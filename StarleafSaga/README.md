# 별잎 연대기 (Starleaf Chronicle)

퀘스트 중심 2D 횡스크롤 RPG (Python + pygame). 최대 레벨 100.

## 실행
```
pip install pygame
python main.py
```

## 조작
| 키 | 기능 |
|---|---|
| ← → / Space | 이동 / 점프 (↓+Space: 발판 아래로) |
| Z | 기본 공격 |
| A S D F G H | 스킬 단축키 (스킬 창에서 스킬 클릭 후 키 입력으로 등록) |
| Q / W | HP / MP 물약 |
| ↑ | 포탈 |
| X 또는 NPC 클릭 | 대화 |
| C E I K L | 능력치 / 장비 / 인벤토리 / 스킬 / 퀘스트 |
| F1 / F5 | 도움말 / 저장 |

## 구조
```
main.py            타이틀, 메인 루프, 입력
game/config.py     화면·물리·색상·폰트
game/formulas.py   레벨 공식 (몬스터 HP/EXP 곡선, 필요 경험치, 사냥 경험치 감소)
game/player.py     레벨업, AP(레벨당 5, 누적), SP, 장비, 버프
game/items.py      장비 생성, 추가옵션, 잠재능력, 큐브, 세트 효과
game/quests.py     퀘스트 판정·진행·보상
game/world.py      맵, 발판 물리, 몬스터 AI, 전투, 드롭
game/ui.py         HUD, 각종 창, NPC 대화
game/draw.py       도형 기반 캐릭터/몬스터 그리기, 스킬 아이콘 로더
data/*.json        스킬, 장비/세트/잠재능력, 몬스터, 맵, NPC, 퀘스트
assets/skills/     스킬 아이콘 이미지 (파일명 = 스킬 id)
```

## 마법사 계열 (2·3·4차 전직마다 3가지 중 선택)
| 계열 | 2차 | 3차 | 4차 | 특징 |
|---|---|---|---|---|
| 화염·독 | 화염술사 | 독염술사 | 업화의 대마도사 | 화상·중독 지속 피해 |
| 얼음·번개 | 빙뢰술사 | 폭풍술사 | 천뢰의 대마도사 | 둔화·빙결(기절)·감전, 광역 |
| 신성 | 성직자 | 사제 | 별의 대사제 | 회복·피해 감소·부활, 영혼형 적 2배 |

각 차수의 스킬은 그 차수에서 고른 계열을 따른다(같은 계열 유지 추천, 혼합 가능). 보스는 기절·둔화 면역.

## 스킬 아이콘
`python tools/make_icons.py --force` 로 스킬 이름에 맞춘 아이콘을 `assets/skills/` 에 다시 생성한다.
직접 만든 이미지를 쓰려면 같은 파일 이름(스킬 id.png)으로 덮어쓰면 된다.

## 밸런스 기준
- 몬스터 HP/EXP/방어력: mlandopt.com 몬스터 도감의 레벨별 수치를 기준점으로 로그 보간
- 난이도 배율(`HP_DIFFICULTY`): 해당 레벨대 장비(잠재능력 없음) 기본 공격 기준
  Lv1 3타 / 30 6타 / 50 11타 / 70 21타 / 80 30타 / 90·100 50타가 되도록 HP를 곱한다
- 최종 보스 녹스: HP x2, 방어력 x1.3, 마법 패턴 6종
  (공허 운석, 추적 암흑 구체+MP 흡수, 안전지대 외 전체 파동, 순간이동 베기 / HP 50% 이하: 피해 85% 감소 장막, 망령 소환, 시전 가속)
- 큐브 등급업 확률: 넥슨 공식 큐브 확률 안내 (수수께끼 큐브 = 명장 큐브, 별빛 큐브 = 블랙 큐브 수치)
- 경험치: 퀘스트 보상은 "퀘스트 레벨의 필요 경험치 x 비율"로 계산. 시뮬레이션 기준 전체 경험치의 약 78%가 퀘스트
- 플레이어보다 6레벨 이상 낮은 몬스터는 사냥 경험치가 단계적으로 감소
