## 2. 장 전환 연출 (짧은 효과음 8개)
1. **별조각 공명음 (2~3초)**: 장 마지막 퀘스트 완료 순간. 배경음악을 잠시 줄이고 별조각별 음색으로 재생. 손등 문양 빛남 + 빛기둥 + 별 파티클.
   바람(플루트풍), 생명(하프풍), 대지(종소리), 태양(금관풍), 얼음(유리음), 하늘(맑은 고음), 공허(낮은 울림)
2. **챕터 클리어 팡파르 (약 5초)**: 화면 중앙에 "N장 완료 · X의 별조각" + 별조각 현황 (예: ★☆☆☆☆☆☆ 1/7)
3. **챕터 타이틀 카드**: 새 마을에 처음 들어갈 때만. 화면 어두워짐 → "2장 · 은빛숲의 노래" 2~3초 → 마을 곡 페이드인

챕터 이름 (퀘스트 창, 세이브 슬롯 카드에도 표시):
프롤로그 낯선 해변 / 1장 바람이 시작되는 곳 / 2장 은빛숲의 노래 / 3장 강철과 불꽃 / 4장 모래에 묻힌 진실 / 5장 얼어붙은 맹세 / 6장 별의 정체 / 종장 공허의 문

## 3. 음향 설정 (메뉴)
- 배경음악 켬/끔, 효과음 켬/끔 따로 + 각각 음량 슬라이더 (0~100%)
- 맵 이동 시 약 1초 크로스페이드
- 설정은 저장되어 다음 실행에도 유지
- 기존 효과음(타격, 레벨업 등)은 그대로 두고 새 효과음 설정을 따르게

## 4. 세이브 슬롯 3개 (A / B / C)
- 타이틀: 슬롯 카드 3개 (이름, 직업, 레벨, 현재 위치, 챕터, 마지막 저장 시각, 엔딩 클리어 여부)
  - 새로 시작 → 슬롯 선택 (사용 중이면 덮어쓰기 확인) / 이어하기 → 슬롯 선택 / 슬롯별 삭제 (확인 1회 더)
- 게임 중 메뉴: "저장하기" (현재 슬롯, 자동 저장도 현재 슬롯만) + "다른 슬롯에 저장" (A/B/C 아무 곳에, 직업 무관)
- 브라우저: 슬롯별 localStorage 키 / EXE: `문서\Hannyomi\save_A.json`, `save_B.json`, `save_C.json`
- 기존 세이브(`arcelia_save_v1`, EXE는 `save.json`)는 슬롯 A로 자동 이전
- 최종 보스 체험 모드는 계속 저장 안 함, 슬롯에 영향 없음
