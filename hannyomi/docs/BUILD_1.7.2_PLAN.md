## 2. 천공 성소 보스: 천공룡 아우렐리온 → 엘드리크 (2단계)
### 2-1. 천공룡 아우렐리온 (새 id `aurelion`, 보스, Lv.89)
- 디자인: 사용자가 공유한 시안을 바탕으로 우리 세계관에 맞춘다 (도감 미리보기 그림 확정)
  - 연보라빛 흰 몸, 뒤로 휜 금빛 뿔, 금빛 테 날개(앞뒤 두 장), 등·꼬리의 금빛 가시, 꼬리 끝 깃 술, 발밑 구름
  - 후광 대신 **일곱 별 고리** (일곱 영웅·일곱 별조각), 가슴 보석 = **하늘의 별조각**, 떠다니는 별조각 결정
  - 1단계(조종당함): 별조각·별 고리·결정·눈이 **보랏빛** + 별조각 둘레 타락의 금. 쓰러지면 흰빛·금빛으로 돌아옴
- 크기 약 220×180 (측면, 보스방을 꽉 채움). 등장할 때는 정면으로 날개를 펴며 포효
- 움직임: 숨쉬기, 날개 퍼덕임, 별 고리 회전, 결정 둥실, 고개 들기(포효), 날갯짓, 날아오르기, 쓰러짐(빛이 빠져나가며 내려앉음)
- 공격 패턴 (기존 보스 패턴 방식을 응용)

| 패턴 | 내용 | 피하는 법 | 기존 방식 |
|---|---|---|---|
| 별의 포효 | 고개를 들면 몸 주변에 원 표시 → 충격파 + 밀려남 | 원 밖으로 | 범위 장판 |
| 천공 돌풍 | 날갯짓으로 바닥을 가로지르는 회오리 2~3개 | 점프 | 높이별 파동 |
| 일곱 별 낙하 | 별 고리의 별이 플레이어 위치에 표시 후 떨어짐 | 계속 이동 | 바닥 솟구침(hands) |
| 천공 비상 (체력 50%, 1회) | 날아올라 잠시 무적, **타락한 별조각 결정 3개** 등장. 제한 시간 안에 모두 부수면 떨어져 그로기, 실패하면 화면을 가로지르는 **별빛 숨결** | 결정 빨리 부수기 | 소환물 처치(chain) |

### 2-2. 2단계 전환과 엘드리크
- 아우렐리온 체력 0 → 쓰러지며 빛이 흰·금으로 돌아옴 → 엘드리크 등장: "쓸모없는 짐승 같으니… 내가 직접 상대해 주마!"
- 엘드리크 패턴·능력치는 지금 그대로 (별빛 사슬, 침묵의 성가, 타락한 별조각, 천공 낙하, 공허 강림)
- **체크포인트**: 2단계에서 쓰러지면 2단계(엘드리크)부터 다시 시작. 보스방을 나가면 처음부터
- 시간 밸런스: 두 단계를 합쳐 지금 엘드리크전의 약 1.5배가 되도록 아우렐리온 체력을 맞춘다 (테스트 모드 Lv.89 기준 측정해서 보고)
- 보상: 엘드리크 처치 시 지금과 같음 (천공 무기 드롭 등). 아우렐리온 단계는 경험치만
- 보스 체력바: 1단계 "천공룡 아우렐리온" → 2단계 "장막의 대사제 엘드리크"로 바뀜
- 음악: 엘드리크 곡을 두 단계 내내 사용 (새 곡 없음)
