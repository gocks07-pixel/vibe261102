## B. 구조를 바꾸는 것 (세이브 변환 필요)

### 1. 각성 큐브 → **공명석** / 잠재 옵션 → **별자리 각인**
- 지금: 큐브를 쓰면 잠재 옵션 전부를 다시 굴리고, 확률로 등급이 오른다 (20% / 6% / 2.5%)
- 1.6.1:
  - 공명석을 쓰면 각인 창이 열리고, **다시 새길 줄 하나를 골라** 그 줄만 다시 굴린다 (나머지는 유지)
  - 등급 상승은 확률이 아니라 **공명 게이지**: 공명석 1개 = 게이지 +1. 반짝임→빛남 5, 빛남→찬란 15, 찬란→별의 축복 35에서 확정 상승 (지금 확률의 평균 사용 횟수와 비슷하게). 오르면 그 등급으로 모든 줄을 새로 새김
  - 장비마다 게이지 저장 (`it.res`). 각인이 없는 장비는 첫 사용 시 "반짝임"으로 깨어남 (지금과 같음)
- 세이브: 기존 장비는 게이지 0에서 시작. 아이템 id `cube` 그대로

### 2. 불꽃석 / 추가 옵션 → **대장장이 "단련"** / **단련 효과**
- 소모품 불꽃석을 없애고, 무기·방어구 상인(대장장이) NPC 대화에 **"🔨 장비 단련"** 추가: 골드를 내고 장비의 단련 효과(옛 추가 옵션)를 다시 굴린다
- 비용: 장비 레벨 × 60 + 500 골드 (Lv.10 약 1,100 / Lv.100 약 6,500)
- 상점·보물상자·보스 드롭에서 불꽃석 제거. 보스 드롭 자리에는 골드 꾸러미, 상자는 공명석 확률 소폭 상향
- 세이브: 가지고 있던 불꽃석은 1개당 **1,500 골드로 환급** (안내 메시지)

### 3. 주문서 3종 + 업그레이드 가능 횟수 → **별빛 각인서 1종** + **각인 칸**
- 지금: 축복(100%, +1) / 용기(70%, +2) / 도박(30%, +3) 주문서, 실패해도 칸 소모
- 1.6.1:
  - **별빛 각인서** 한 종류 (id `scroll_100` 재사용). 성공률은 **다음 칸 단계**로 정해진다: 1칸 100% · 2칸 90% · 3칸 80% · 4칸 65% · 5칸 50% · 6칸 40% · 7칸 30%
  - 성공 시 +1 강화하고 칸 하나를 채움. **실패하면 칸은 그대로 남고 각인서만 사라짐** (다시 도전 가능)
  - 강화 +1당 능력치를 지금의 **1.5배**로 올려, 평균 강화 효과가 지금과 비슷하도록 (부위별 칸 수 7/5/3은 유지)
  - 특수 효과 24종 부여는 유지: 높은 칸일수록 부여 확률·수치가 좋아짐 (1칸 10% … 7칸 50%)
  - 강화 결과 창, 툴팁 문구 "남은 업그레이드 가능 횟수" → "각인 칸 n / 7"
- 드롭: 일반 몬스터 2% → 각인서 1장. 보스는 지금 주문서 장수만큼 각인서
- 세이브: 용기의 주문서 1장 → 각인서 2장, 도박의 주문서 1장 → 각인서 3장으로 변환. 이미 강화된 장비의 +수치와 남은 칸은 그대로 인정

### 4. 능력 포인트 (AP) 구조
- 지금: 레벨당 AP 5를 직접 배분
- 1.6.1: 레벨당 **능력 포인트 4 + 직업 주스탯 자동 +1** (합계는 같아 밸런스 유지, 구조는 다름). 표류자는 자동 성장 없이 4 + 1을 직접 배분
- 세이브: 이미 배분한 스탯은 그대로. 남은 AP는 그대로 남은 능력 포인트로

### 5. 마나 보호막 계열 → **별의 장막** (흡수 보호막)
- 지금: 받는 피해 일부를 MP로 대신 받음 (`manaShield`: 마나 보호막, 서리 갑옷)
- 1.6.1: 사용하면 **최대 HP의 n%만큼 피해를 흡수하는 보호막**이 생기고, 보호막이 깨지거나 시간이 끝나면 사라짐 (n = 스킬 레벨에 따라 10~30%)
  - 마법사 1차 "별의 장막", 2차 B "서리 갑옷"(방어력 + 보호막)에 적용. 테스트 모드 캐릭터도 같이
- 세이브: 저장된 버프는 없으므로 변환 불필요

### 6. 기본 키
- 기본값: 점프 **Space**, 공격 **Z** (Alt·Ctrl 기본 지정 제거, 키 설정에서는 계속 고를 수 있음)
- 세이브: 사용자가 이미 바꾼 키 설정은 그대로 유지
