# 전체 완주 시뮬레이션 계획서 (Lv.1 → 엔딩 3종, 전체 직업)

2026-11-06 작성. 사용자가 "진행해 줘"라고 하면 만든다. 브랜치 `hannyomi-mobile`. **시뮬레이션 동안 게임 코드 · 밸런스는 바꾸지 않는다** — 찾은 버그 · 밸런스 문제는 목록으로 보고하고, 고칠지는 사용자가 정한다.

## 목적
- 처음부터 끝까지 실제로 진행되는지 (막히는 퀘스트 · 오류 · 멈춤이 없는지)
- 장비 수준(약함 · 보통 · 강함)에 따라 사냥 · 보스 · 엔딩까지의 밸런스가 맞는지
- 보스를 몇 번 만에 깨는지 → **11번째 도전에 추가 보정을 넣을지** 사용자가 정할 자료

## 무엇을 돌리나
- **직업 8갈래** (전사 · 궁수 · 마법사 · 도적 × 각성 Ⅱ 두 갈래) × **장비 3단계** = **24판**
- 한 판 = 새 캐릭터 Lv.1 → 튜토리얼 → **메인 퀘스트 91개 + 서브 퀘스트 33개 전부** → 녹스 처치 → **엔딩 3종**
  - 별의 선택에서 **희생(봉인)** → 엔딩 → 엘마의 "별조각의 기억"으로 돌아가 **구원(정화)** → 엔딩 → 다시 돌아가 **✦ 히든(공명)** → 엔딩 (히든 조건 서브 퀘스트 6개가 모두 끝나 있어야 함 → 조건이 채워졌는지도 확인)
- 휴대폰판 그대로 (터치 모드, 2차-1.3 까지의 자동 사냥 · 자동 흡수 · 자동 물약 · 최고 장비 등)

## 완주 봇 (새 파일 `docs/drafts/sim/fullrun.js`)
실제 게임을 띄워 **프레임만 빨리 넘긴다** (그리기 생략, 약 400배 속도 — 게임 60초 ≈ 0.14초 측정). 게임 규칙 · 경험치 · 드롭 · 확률은 그대로.

1. **퀘스트**: 받을 수 있는 메인 · 서브 퀘스트를 모두 받고, 목표를 채우면 보고 (대화는 NPC 와 대화하는 것과 같은 함수로, 선택지는 첫 번째 = 수락)
   - 목표 2종뿐: **몬스터 처치(113개)** · **아이템 모으기(28개)** → 그 몬스터가 나오는 사냥터로 가서 **자동 사냥**(G.Play)으로 채움
   - 각성 시험(28개): 직업 갈래는 판마다 정한 갈래로 고름
2. **이동**: 맵 사이는 바로 옮겨 간다 (포탈을 걸어가는 대신. 이동 시간은 밸런스와 관계없어서 생략, 기록에는 "이동 생략"으로 표시)
3. **레벨이 모자라면**: 다음 메인 퀘스트 레벨까지 알맞은 사냥터(내 레벨 ±3 몬스터)에서 자동 사냥 → **모자란 레벨 · 걸린 사냥 시간을 장마다 기록** (2.1 때 "퀘스트 사이 1~3레벨 사냥 필요할 수 있음"을 확인)
4. **능력 · 기술 포인트**: 스탯 창 "추천대로 모두 올리기"(주스탯), 기술 포인트는 공격 스킬 → 버프 → 패시브 순으로 최대까지. 스킬 칸 = 공격 4 + 버프 2 (예상 피해가 높은 것)
5. **물약**: 마을에 들를 때 골드로 그 지역 물약을 채움 (HP 물약 100 · MP 물약 50 목표), 자동 물약 HP 50% · MP 30%. **골드가 모자라면 기록** (경제 밸런스 확인)
6. **쓰러지면**: 실제처럼 마을에서 부활 → 다시 그 퀘스트로 (사냥터에서 쓰러진 횟수 기록)

## 장비 3단계
| | 약함 | 보통 | 강함 |
|---|---|---|---|
| 장비 | 퀘스트 보상 + 주운 것만 | 약함 + **상점에서 레벨에 맞는 장비 구입**(골드 되는 만큼) | 보통 + **그 지역 세트 장비**(보스 드롭 세트를 모은 것으로 가정해 지급) |
| 입기 | ⭐ 최고 장비 입기 | ⭐ 최고 장비 입기 | ⭐ 최고 장비 입기 |
| 강화 | 없음 | 없음 | **별빛 각인서로 부위마다 +3~5**, 공명석으로 각인 등급 "빛남" |
| 목표 | 질 수 있음 (참고) | **보스 70% 안팎** (지금까지의 목표) | 쉽게 |

- "강함"의 세트 · 강화는 실제로 얻을 수 있는 양에 맞춰 장마다 지급 (드롭 확률 · 보증 횟수 기준). 지급한 목록은 결과에 적음

## 보스 도전 규칙 (보스 방 8곳: 쉘로크 · 바르크 · 모르웬 · 그라운더 · 파라칸 · 카이엔 · 아우렐리온+엘드리크 · 녹스)
| 도전 | 방법 | 레벨 |
|---|---|---|
| 1~5번 | **직접 플레이**: 2.1 시뮬레이터의 "휴대폰 직접" 사람 모델 (예고 공격을 30% 확률로 피함, 2차-1.3 측정과 같음) | 그때 레벨 |
| 6번 | **자동 전투** (5번 패배 후 열림, 파라칸 · 녹스는 받는 피해 ×0.75) | 그때 레벨 |
| 6번도 지면 | "자동으로도 못 깸" 개수 +1 → **Lv.100 까지 자동 사냥으로 키움** (이미 100이면 건너뜀) | |
| 7~10번 | 자동 전투 | Lv.100 |
| 10번까지 지면 | "10번 실패" 개수 +1 → 그 보스는 시뮬레이터가 건너뛰고(결과에 표시) 다음으로 | |

- 보스마다 기록: 몇 번째에 깼는지 · 직접/자동 · 걸린 시간 · 쓰러진 원인(패턴) · 물약 수
- **이 표로 "11번째 도전에 추가 보정"을 넣을지 사용자가 정함**

## 찾는 버그 (자동으로 검사 · 기록)
- 게임 오류(콘솔 · 오류 기록 `G.ErrLog`), **10분(게임 시간) 동안 진행이 없으면 "멈춤"**으로 기록하고 그 자리 상태(맵 · 퀘스트 · 위치)를 저장
- 받을 수 없는 / 끝낼 수 없는 퀘스트, 나오지 않는 퀘스트 아이템, 갈 수 없는 맵, 각성 퀘스트가 안 열림
- 세이브 → 불러오기를 장마다 한 번 (불러온 뒤 같은 상태인지)
- 엔딩 3종 크레딧까지 나오는지, 히든 조건 6/6 이 채워지는지
- 자동 사냥이 갇히는 곳 (발판 · 벽), 자동 흡수 · 최고 장비가 이상하게 동작하는 곳

## 정해진 것 (2026-11-06 사용자 확인)
1. 보스 "직접 플레이" 모델: **휴대폰 직접 (예고 공격 30% 회피)**
2. 보스 도전 횟수: **1~5 직접 → 6 자동 → (실패 시) Lv.100 까지 → 7~10 자동 → 10번 실패 개수** (위 표 그대로)
3. 장비 3단계를 **각각 따로 처음부터 끝까지** 플레이 (8갈래 × 3 = 24판). 결과 비교 기준(보스 직접 플레이 승률): **약함 50% 안팎 · 보통 70% 안팎 · 강함 90% 이상** — 결과를 읽는 기준일 뿐, 맞추려고 게임을 바꾸지 않음
