## 1. 지금 문제
- 버프 표시가 **왼쪽 위 지역 이름과 미니맵 사이에 30px 아이콘 + 숫자**로만 나와서 거의 보이지 않음. 효과 내용은 알 수 없음
- 나쁜 효과(독·둔화·절망·저주·침묵·좌우 반전)는 **화면에 표시가 없음** (걸리는 순간 글자만 잠깐 뜸)

## 3. 스킬 아이콘 전부 새로 그리기
- 대상 **156개** (계획 때 116개로 셌으나 1.5에서 추가된 직업별 스킬 40개를 빠뜨림 → 함께 그림): 공통 스킬 3개(돌 던지기 · 응급 처치 · 2단 점프)를 뺀 전부. **같은 그림 0개**, **눈 그림 사용 안 함**
- 지금처럼 코드로 그린 SVG (이미지 파일 없음). 배경색은 지금처럼 속성 색(불·바람·대지·마법·그림자·독·성스러움)
- 테두리 모양으로 종류 구분: **공격 = 둥근 사각형 · 버프 = 방패꼴 · 패시브 = 원**
- 그림은 1.7.10~1.7.11에서 바뀔 스킬 모습에 맞춰 미리 그린다 (예: 화염구 = 불덩이, 저격 = 긴 조준선)
- 스킬창 · 단축키 칸 · 새 버프 표시 · 툴팁에 모두 자동 반영
- (계획) 구현 첫 단계에서 아이콘을 한 장의 시트 그림으로 먼저 보여 드리고**, 고칠 것을 반영한 뒤 게임에 넣는다

### 아이콘 목록
**전사** — 강타: 내려찍는 검 · 회전 베기: 원을 그리는 검 · 돌격: 어깨 돌진 · 강철 의지: 강철 흉갑 · 검술 수련: 교차한 두 검
- 대검사: 대지 가르기 = 갈라진 땅과 대검 · 화염 회전참 = 불꽃 소용돌이 검 · 분노 = 불꽃 주먹 · 대검 숙련 = 대검 한 자루
- 파쇄자: 파쇄격 = 금 간 바위 · 대지진 = 퍼지는 충격파 고리 · 돌진 강타 = 끌리는 대검과 불꽃 · 투지 = 불끈 쥔 주먹
- 천붕검제: 천붕참 = 하늘에서 내려오는 거대한 검 · 멸천 낙화 = 떨어지는 불타는 검들 · 천붕검제의 각성 = 날개처럼 펼친 대검들 · 극의 = 대검 위의 별
- 방패기사: 방패 강타 = 방패와 별 · 성스러운 파동 = 퍼지는 금빛 고리 · 수호의 맹세 = 손을 얹은 방패 · 방패 숙련 = 방패 문장
- 철벽기사: 성벽 돌진 = 방패와 속도선 · 심판의 망치 = 빛나는 망치 · 성역 = 바닥의 성역 문양 · 불굴 = 무너지지 않는 성벽
- 불멸의 수호자: 불멸의 일격 = 교차한 검과 방패 · 천상의 심판 = 내려꽂히는 빛의 창 · 불멸 = 금빛 날개 방패 · 수호자의 긍지 = 왕관 얹은 방패

**궁수** — 연발 사격: 겹친 화살 두 개 · 화살 비: 위에서 떨어지는 화살 · 후퇴 사격: 뒤로 휜 화살표와 활 · 매의 눈: 매 깃털 · 활 수련: 활
- 사냥꾼: 삼연사 = 부채꼴 화살 셋 · 폭풍 화살 = 소용돌이 감은 화살 · 바람의 축복 = 바람 날개 신발 · 사냥꾼의 본능 = 짐승 발자국
- 매의 사수: 매의 일격 = 날개 편 매 · 화살 폭풍 = 회오리와 화살 · 회피 사격 = 구르는 화살표 · 매의 눈 숙련 = 매의 옆얼굴
- 천궁: 천궁 연사 = 빛나는 활 · 천공의 화살비 = 하늘의 문과 화살 · 천궁의 각성 = 깃털 날개 · 궁극의 궁술 = 과녁 정중앙의 화살
- 석궁수: 관통 볼트 = 굵은 볼트 · 산탄 볼트 = 흩어지는 탄 · 조준 = 십자선 · 석궁 숙련 = 석궁
- 저격수: 저격 = 긴 조준선 · 연쇄 폭발 볼트 = 폭발하는 볼트 · 은신 사격 = 연막과 볼트 · 저격수의 집중 = 조준경
- 섬광의 저격왕: 섬광 저격 = 빛줄기 · 섬광 탄막 = 줄지어 박힌 볼트 · 저격왕의 각성 = 조준경 왕관 · 극한의 조준 = 표적 한가운데 점

**마법사** — 마나 탄: 별빛 구슬 · 마나 폭발: 마법진 · 별빛 도약: 별과 점선 · 별의 장막: 별 방울막 · 마나 순환: 순환하는 두 물방울
- 화염술사: 화염구 = 불덩이 · 화염 폭발 = 터지는 불꽃 · 화염 장막 = 불꽃 고리 · 화염 숙련 = 불꽃 두루마리
- 업화술사: 업화 = 검붉은 불꽃 · 화염 기둥 = 솟는 불기둥 · 불꽃 폭풍 = 불 회오리 · 업화의 심장 = 불타는 심장
- 화염군주: 화염군주의 창 = 불의 창 · 대화재 = 불비 · 화염군주의 각성 = 불꽃 왕관 · 불멸의 불꽃 = 꺼지지 않는 촛불
- 빙뢰술사: 냉기 광선 = 얼음 광선 · 연쇄 번개 = 꺾이는 번개 · 서리 갑옷 = 얼음 결정 갑옷 · 빙뢰 숙련 = 눈송이와 번개
- 폭풍술사: 썬더 스톰 = 먹구름과 번개 · 빙결 폭발 = 깨지는 얼음 · 얼음 창 = 얼음 창 · 폭풍의 눈 = 소용돌이 구름
- 천둥의 현자: 천둥의 심판 = 번개 기둥 · 절대 영도 = 눈꽃 결정 · 현자의 각성 = 번개와 얼음 고리 · 현자의 지혜 = 열린 마법서

**도적** — 쌍단검 연격: 교차한 단검 · 표창 투척: 표창 · 그림자 도약: 그림자 실루엣 · 독 바르기: 독방울 맺힌 단검 · 단검 수련: 단검 한 자루
- 암살자: 삼연 표창 = 표창 셋 · 급소 찌르기 = 단검과 표식 · 암살 준비 = 두건 그림자 · 표창 숙련 = 표창 묶음
- 그림자추적자: 그림자 표창 = 돌아오는 표창 · 암영 일섬 = 일직선 칼날 잔상 · 표창 폭풍 = 원을 그리는 표창들 · 추적자의 본능 = 그림자 발자국
- 야천: 야천 난무 = 분신 셋 · 칠흑의 밤 = 초승달 · 야천의 각성 = 겹친 실루엣 · 그림자 극의 = 검은 별
- 쌍검사: 쌍검 난무 = X자로 교차한 두 검 · 칼날 회오리 = 칼날 회오리 · 무희의 걸음 = 춤추는 발 · 쌍검 숙련 = 나란한 두 검
