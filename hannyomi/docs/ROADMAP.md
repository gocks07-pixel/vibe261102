# 완성까지 로드맵 (1.4 이후 계획)

2026-11-03 사용자와 확정. 1.4가 끝나면 이 순서대로 진행한다.
1.4까지 하면 "처음부터 엔딩까지 소리와 함께 플레이할 수 있는 버전"이 되지만, 완성은 아니다.

## 1.3에 이미 있는 것
- 튜토리얼부터 엔딩 2종까지 스토리 전체 (Lv.1~100)
- 1~4차 전직 8갈래, 보스 8종, 장비·세트·주문서·잠재 옵션
- 키 설정, 지도, 길 안내 (최종 보스 체험 모드는 1.6에서 제거)

## 1.4에서 채울 것
- 배경음악 28곡, 장 전환 연출, 음향 설정, 세이브 슬롯 3개 (`docs/BUILD_1.4_PLAN.md`)

## 1.4 이후에도 남는 것
### 처음 약속했지만 아직 없는 것
- 창고 기능: 창고지기 NPC는 있지만 "준비 중"이라는 말만 한다
- 2~4차 스킬 수: 처음 설계는 차수마다 6/6/5개였는데, 지금은 4개씩이다

### 부족하거나 확인이 안 된 것
- 직접 플레이 검증: 자동 시뮬레이션으로 진행 경로와 오류는 확인했지만, 사람이 처음부터 끝까지 해 본 적은 없다
- 밸런스: 4~6장에서 퀘스트 사이에 1~3레벨 정도 사냥이 필요할 수 있고, 보스 난이도는 손으로 조정하지 않았다
- 콘텐츠 양: 서브 퀘스트가 장마다 1~2개로 적다
- 그래픽: 새 몬스터 대부분은 기존 모양에 색과 크기만 바꾼 것이다

### 배포 관련
- EXE 빌드: 설정 · 메인 프로세스는 가짜 Electron 으로 시험 완료. 실제 Windows EXE 는 사용자 PC 에서 처음 만든다 (`docs/EXE_빌드_안내.md`). 처음 빌드 때 오류가 나면 마지막 줄을 받아 고친다
