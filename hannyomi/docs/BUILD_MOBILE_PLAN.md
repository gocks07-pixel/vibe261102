# 모바일 1차 계획서 (아이폰 · 갤럭시)

2026-11-05 작성. 사용자가 "진행해 줘"라고 하면 구현한다. 브랜치 `hannyomi-mobile` 에만 커밋·푸시 (`hannyomi-backup` 은 EXE 작업 중이라 건드리지 않음).

## 정해진 것
- 방식: 웹(PWA)으로 배포 → 아이폰은 사파리 "홈 화면에 추가", 갤럭시는 크롬. 나중에 원하면 갤럭시 APK
- 버전 숫자는 그대로(2.1.0). 화면에 "모바일" 표시만 붙인다. 두 브랜치를 합칠 때 2.2.0
- 1차 = M1 화면 맞추기 · M2 터치 조작 · M4 세이브 지키기 (플레이 가능 + 세이브 안전)
- 2차 = M3 창 터치 개선 · M5 앱처럼 설치 · M6 성능 · M7 배포
- 앱 아이콘: 1차가 끝나면 시안 몇 개를 만들어 사용자가 고른다 (그때까지 임시 아이콘)

## 지키는 것
- 내부 id · 세이브 형식(`G.Save.VERSION` 4) · `hny_*` 키는 바꾸지 않는다
- 게임 규칙 코드는 건드리지 않는다. 터치 버튼은 "키를 누른 것"으로 바꿔 `G.Input` 에 넣는다 → 키 설정(`G.Keys.map`)도 그대로 따른다
- 터치 기능은 터치 화면에서만 켜진다. PC 브라우저 · EXE 는 지금과 똑같이 동작
- 테스트 모드(`src/dev.js`)는 그대로 둔다 (브라우저판은 원래 불러오지 않음)
- 그림 파일 없이 코드로 그린다 (버튼 문양도 CSS · SVG)

## M1. 화면 맞추기
지금은 1280×720 화면을 `G.Game.resize()` 로 비율을 유지해 줄인다. 아이폰 가로(약 844×390)에서는 0.54배, 좌우에 검은 띠가 약 75px씩 생긴다.

1. `index.html` viewport: 확대 금지, 노치 영역까지 쓰기 (`viewport-fit=cover`), 홈 화면 실행 시 전체 화면용 meta
2. 확대 · 스크롤 · 당겨서 새로고침 · 길게 눌러 글자 선택/돋보기 막기 (`touch-action`, `overscroll-behavior`)
3. `resize()` 가 `visualViewport` 크기와 노치 · 홈 바 여백(safe-area)을 빼고 계산. 주소창이 나왔다 들어갈 때도 다시 맞춘다
4. 세로로 들면 "가로로 돌려 주세요 📱↻" 화면 (게임은 잠시 멈춤)
5. 메뉴에 "전체 화면" 버튼 (갤럭시 크롬. 아이폰은 홈 화면에 추가하면 자동 전체 화면이라 안내 문구로)
6. 소리: 지금은 키보드 · 마우스를 눌러야 소리가 켜진다 (`src/core/audio.js` unlock) → 첫 터치(`pointerdown` · `touchend`)에도 켜지게. 아이폰 무음 스위치를 켜면 소리가 안 날 수 있다는 안내 한 줄 (처음 한 번)
7. 시작 화면 오른쪽 아래 버전 표시: `v2.1.0 모바일`. 버그 신고 · 오류 기록에도 "모바일"과 기기 정보(아이폰/갤럭시, 화면 크기)

## M2. 터치 조작 버튼
게임 화면(#game)은 줄어들지만 버튼은 줄어들지 않게 화면 맨 위에 따로 얹는다 (손가락 크기 그대로 약 56~64px). 반투명, 여러 손가락 동시에 (이동하면서 점프 · 공격).

```
┌──────────────────────────────────────────────────────────────┐
│ [맵 이름]                     [스탯][장비][인벤][스킬][퀘][지도][≡]│
│                                                    [퀘스트 안내]│
│                                                              │
│                                                              │
│                                          [1] [2] [3]          │
│     [↑]                                  [4] [5] [6]  [HP][MP]│
│ [←]     [→]                         [대쉬]                     │
│     [↓]                                    [공격]   [점프]      │
└──────────────────────────────────────────────────────────────┘
```

1. 왼쪽 방향 패드: 누른 채 손가락을 미끄러뜨리면 방향이 바뀐다. ↑ = 포탈 · NPC 대화, ↓ 누른 채 점프 = 발판 아래로. 좌우 동시 처리는 지금처럼 `lastH`
2. 오른쪽 행동 버튼: 공격(누르고 있으면 연속), 점프(공중에서 한 번 더 = 2단 점프, ↑+점프 그대로), 대쉬
3. 스킬 1~6: 하단 상태창의 스킬 칸과 같은 아이콘 · 재사용 대기 · MP 부족 표시. 빈 칸은 흐리게
4. HP · MP 물약 버튼: 남은 개수, 자동 물약 켜짐 표시 (지금 HUD 와 같은 규칙)
5. 위쪽 창 버튼: 스탯 · 장비 · 인벤토리 · 스킬 · 퀘스트 · 지도 · ≡ 메뉴(Esc 와 같음: 열린 창이 있으면 닫고, 없으면 메뉴). 🐞 버그 신고는 메뉴 안에 이미 있음
6. 대화: 대화창이 열려 있으면 게임 화면을 누르면 다음으로 (Enter 와 같음). 선택지 버튼은 지금처럼 직접 누름
7. NPC · 포탈 누르기: 지금 `mousedown` → 탭도 똑같이 동작하는지 확인 (필요하면 `pointerdown` 으로)
8. 장비 · 인벤토리 "더블클릭"(입기 · 사용): 휴대폰은 더블클릭이 잘 안 잡혀서 "같은 칸을 빠르게 두 번 탭"을 더블클릭으로 처리. 오른쪽 위 퀘스트 두 번 탭 = 길 안내도 같이 해결 (원래 2차 M3 항목이지만 이게 없으면 장비를 못 입어서 1차에 넣음)
9. 메뉴 → "터치 버튼 설정" 창: 크기(작게/보통/크게), 투명도, 좌우 바꾸기(왼손잡이), 터치 버튼 켜기/끄기(자동 · 항상 · 끔). 저장은 새 키 `hny_touch` (세이브와 별도, 기존 설정 `hny_settings` 형식도 그대로)
10. 컷신 · 엔딩 · 캐릭터 만들기 · 타이틀에서는 버튼 숨김. 캐릭터 이름 입력은 휴대폰 자판이 뜨는지 확인
11. 휴대폰에서 F1 조작법 창 → "버튼 안내" 그림으로, 키 설정 메뉴는 숨김 (PC 는 그대로)

새 파일: `src/core/touch.js` (버튼 → 키 입력), `src/ui/mobile.js` (버튼 그리기 · 설정 창 · 세로 안내), `css/mobile.css`

## M4. 세이브 지키기
아이폰 사파리는 오래 안 쓰면 저장 데이터를 지울 수 있고, 창을 닫을 때 `beforeunload` 가 오지 않아 마지막 진행이 저장되지 않을 수 있다.

1. 앱을 내리거나 다른 앱으로 갈 때 저장: `pagehide` · `visibilitychange`(숨김) 에서 `G.Game.save(true)` (PC 에도 해가 없음)
2. 저장 공간 지키기 요청: `navigator.storage.persist()` (갤럭시 크롬은 대부분 허락, 아이폰은 홈 화면에 추가했을 때 효과)
3. **세이브 내보내기** (메뉴 + 타이틀의 슬롯 고르기 화면)
   - 파일로 저장: `save_A.json` — EXE 의 `문서\RPG Adventure\Save Data\save_A.json` 과 같은 내용 (`{v, slot, time, d}`)
   - 복사하기: 같은 내용을 글자로 복사 → 카카오톡 "나에게 보내기"에 붙여 넣어 보관
4. **세이브 가져오기**
   - 파일 고르기 또는 글자 붙여 넣기 → 어느 슬롯에 넣을지 선택 → "Lv.37 ○○ (전사) 를 슬롯 B 에 넣을까요?" 확인
   - 덮어쓸 슬롯에 세이브가 있으면 먼저 자동 백업 (`_backup`, 지금 있는 방식)
   - 옛 버전 세이브도 불러올 때 `G.Save.upgrade()` 가 그대로 변환. 형식이 이상하면 "세이브 글자가 잘렸어요" 안내하고 아무것도 바꾸지 않음
   - EXE 세이브 ↔ 휴대폰 세이브를 서로 옮길 수 있다
5. 사파리에서 홈 화면에 추가하지 않고 하고 있으면 처음 한 번 "홈 화면에 추가하면 세이브가 더 안전해요 (공유 → 홈 화면에 추가)" 안내 + "가끔 세이브 내보내기를 해 두세요"

## 고치는 기존 파일 (작은 수정만)
- `index.html`: viewport · meta, `css/mobile.css` · `touch.js` · `mobile.js` 불러오기
- `src/main.js`: `resize()` (safe-area · visualViewport), `pagehide` 저장, 대화 중 화면 탭
- `src/core/audio.js`: 터치로 소리 켜기
- `src/ui/ui.js`: 두 번 탭 = 더블클릭, 창 끌기를 손가락으로도 (`mousedown` → pointer)
- `src/ui/windows2.js`: 메뉴에 "터치 버튼 설정 · 세이브 내보내기/가져오기 · 전체 화면" (휴대폰에서만 보이는 버튼은 휴대폰에서만)
- `src/ui/windows.js`: 버전 표시 "모바일", 슬롯 화면에 내보내기/가져오기
- `src/core/save.js`: 내보내기 · 가져오기 함수 (읽기 · 쓰기 방식은 그대로, 형식 변경 없음)
- `src/ui/bugreport.js` · `src/core/errlog.js`: "모바일" · 기기 정보 한 줄
