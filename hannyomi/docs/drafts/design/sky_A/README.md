## 1차 시안 1~3 (sky1.png · skyreal.js G.SkyReal · sheet.js)
- 구름: 작은 덩어리 140개를 적란운(위 둥글 · 아래 평평) 모양으로 한 장에 그린 뒤 세로 음영 + 덩어리마다 윗면 빛 · 아랫면 그림자 → 원 겹침이 안 보이고 뭉게구름 결
- 번개: 갈라지는 가지 + 바깥 빛 / 비: 비스듬한 빗줄기 / 해: 흰 핵 → 노랑 · 주황 코로나 + 빛살 + 렌즈 빛
- 1 천궁 폭풍우: 가 거대한 적란운 + 비 + 번개 · 나 먹구름 + 회오리 바람 (잎 날림)
- 2 썬더 스톰 · 천둥 신의 분노: 가 먹구름 띠 + 속에서 푸른 번쩍 · 나 가 + 아래로 갈라지는 파란 번개
- 3 태양 낙하: 가 눈부신 해 (빛살 · 렌즈 빛) · 나 불타는 태양 (표면 불꽃 · 붉은 코로나)
