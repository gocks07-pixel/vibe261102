## 1차 시안 1~3 (sky1.png · skyreal.js G.SkyReal · sheet.js)
- 구름: 작은 덩어리 140개를 적란운(위 둥글 · 아래 평평) 모양으로 한 장에 그린 뒤 세로 음영 + 덩어리마다 윗면 빛 · 아랫면 그림자 → 원 겹침이 안 보이고 뭉게구름 결
- 번개: 갈라지는 가지 + 바깥 빛 / 비: 비스듬한 빗줄기 / 해: 흰 핵 → 노랑 · 주황 코로나 + 빛살 + 렌즈 빛
- 1 천궁 폭풍우: 가 거대한 적란운 + 비 + 번개 · 나 먹구름 + 회오리 바람 (잎 날림)
- 2 썬더 스톰 · 천둥 신의 분노: 가 먹구름 띠 + 속에서 푸른 번쩍 · 나 가 + 아래로 갈라지는 파란 번개
- 3 태양 낙하: 가 눈부신 해 (빛살 · 렌즈 빛) · 나 불타는 태양 (표면 불꽃 · 붉은 코로나)
- 2번 수정: 잘 안 보임 → 구름 더 크고 진하게(700×210), 속 · 둘레 푸른 번쩍 + 바깥 빛, 구름 양옆 가지 번개, 번개 굵게 (sky1_row2.png)
- **1~3 결정: 1 가 (적란운 + 비 + 번개) · 2 가 (먹구름 띠 + 푸른 번쩍, 크고 진한 2차) · 3 가 (눈부신 해)**

## 2차 시안 4~6 + 떨어지는 돌 (sky2.png · skyreal2.js · `ROWS2=1 node sheet.js`)
- 4 천공의 화살비: 가 구름이 갈라지며 쏟아지는 빛 · 나 바람의 문 (도는 구름 고리)
- 5 칠흑의 밤 · 야천 멸살: 가 진짜 달 (크레이터 · 달무리) + 별 + 어두운 밤 · 나 보랏빛 달 + 지나가는 구름
- 6 천둥의 심판: 가 작은 먹구름에서 내리꽂는 번개 + 땅 충격 빛 · 나 하늘 번쩍 + 번개 세 줄기 (가지 적게, R.BR)
- 참고 떨어지는 돌 (유성 낙하 · 태양 낙하): 가 용암 금 간 바위 + 불꼬리 · 나 하얗게 빛나는 별똥
- **4~6 결정: 4 가 (구름이 갈라지며 쏟아지는 빛) · 5 나 (보랏빛 달 + 지나가는 구름) · 6 나 수정 (하늘 번쩍 + 먹구름에서 번개 세 줄기, S.s6c, sky3.png `ROWS3=1`) · 떨어지는 돌 나 (하얗게 빛나는 별똥)**
