출처: 사용자가 준 설계 데이터(눈 5종 겹 순서 · 좌표) + 함수 `drawCustomizedMaleEye` 를 우리 캐릭터(꾸미기 시안 C)에 맞게 고친 것.

|---|---|---|---|---|
| `sharp_clear` | A 날카롭고 또렷한 눈 | 굵은 사다리꼴, 바깥이 올라감 | 눈꼬리 올라감, 굵은 윗선 | 일자 입 · 홍조 없음 |

## 원래 함수에서 고친 점
1. 왼쪽 눈은 좌우를 뒤집어 그림 (원래는 두 눈썹이 같은 방향으로 기울었음)
2. 눈 크기를 우리 2등신 얼굴에 맞춤: 단위 `u = 눈너비(hr*eyeW) * 1.15 / 9`, 세로 ×1.25
3. 설계 데이터의 입 · 볼 홍조를 넣음 (원래 함수에는 없었음)
4. D · E 눈꺼풀: 회색 반투명 사각형 → 피부색 눈꺼풀 + 아래로 옅어지는 그림자
5. 눈동자 색: 종류별 고정 색 대신 **캐릭터가 고른 눈 색**으로 위 진하게 · 아래 밝게 (종류별 고정 색으로 바꾸려면 `m5eye` 의 눈동자 그라데이션만 바꾸면 됨)

## 파일
- `male_eyes_A.js`: 눈 5종 데이터(`M5`) + 그리기(`m5eye`, `faceM5`). 쓰는 도우미: `PI` · `sh(색, 밝기)` · `grad(ctx, x0, y0, x1, y1, 색들)` (outfit.js 에 같은 역할 함수가 있음)
- `mock_renderer.js`: 시안 전체 그리기 코드 (시안 C 얼굴 · 몸 · 머리 + 이 눈). `face()` 첫 줄에서 `M5[L.eye]` 면 `faceM5` 로 그림
- `render_preview.js`: `node render_preview.js` → `preview.png` (playwright 필요)
- `preview.png`: 시안 그림 (이마가 보이는 머리 · 앞머리 있는 머리 · 게임 크기)

## 게임에 넣을 때 (1번 꾸미기 구현과 함께)
- 지금 게임 얼굴은 `src/render/sprites.js` 의 `face` (작은 눈 4종 + 깜빡임). 1번 꾸미기에서 얼굴을 시안 방식으로 바꿀 때 남자 눈 목록에 이 5종을 넣는다
- 눈 깜빡임은 이 눈에 맞게 새로 (윗눈꺼풀 선만 그리기)
- 눈 id 는 새로 추가하는 값이라 옛 세이브의 눈(round · big · smile · sharp)은 그대로 두거나 세이브 변환에서 대응을 정한다
- 앞머리가 눈썹을 가리면 A · D · E 의 느낌이 약해짐 (눈썹이 핵심)
