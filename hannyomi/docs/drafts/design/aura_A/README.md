# 버프 모습 시안 A — 천궁의 각성 (궁수 a 4차, 2026-11-13)
- 사용자: 등 뒤 회색 부채 같은 모습이 아쉬움 → 다른 모습 시안. 몬스터 겉 테두리는 "나 테두리 옅게"로 결정 (빌드 때 같이)
- 지금: 연두 깃털 8장을 빛 더하기(lighter)로 그려 어두운 배경에선 탁한 회색 · 밝은 배경에선 흰 부채
- 가 바람 깃털 날개 (칼깃 · 덮깃 · 작은 깃, 흰색 → 하늘색) / 나 금빛 별 활 (등 뒤 큰 빛 활 + 시위 자리 별 셋) / 다 회오리 바람 (몸 둘레 바람 리본 + 잎 · 깃털) / 라 매의 눈 (머리 위 금빛 매 문양 + 눈)
- 모두 색을 직접 칠함 → 어두운 · 밝은 배경 모두 또렷 → `aura_a.png` (위: 동굴 · 아래: 하늘)
- 다음 요청 예정: 스킬 연출의 구름 · 해 등 도형을 겹친 모양 → 진짜 구름 · 해처럼

## 시안 B — 다른 4차 버프 7종 (`aura_b.js` · `aura_b.png`, 지금 · 가 · 나)
- 사용자: 천궁의 각성은 나 또는 라로 결정 예정
- 전사 a 천붕검제: 가 칠한 불꽃 대검 다섯 / 나 등 뒤 불타는 거대 검
- 전사 b 불멸: 가 등 뒤 금빛 방패 문장 + 빛살 / 나 칠한 금빛 날개 + 천사 고리
- 궁수 b 저격왕 (지금 모습 없음): 가 앞을 겨누는 조준 고리 / 나 등 뒤에 떠 있는 대지 화살 셋
- 마법사 a 화염군주: 가 칠한 불꽃 왕관 / 나 등 뒤 불꽃 고리
- 마법사 b 현자: 가 발밑 마법진 + 오르는 빛 / 나 둘레를 도는 마법책 셋
- 도적 a 야천: 가 보라 그림자 분신 둘 / 나 등 뒤 초승달 + 박쥐 날개 그림자
- 도적 b 검무: 가 몸 둘레 도는 독 단검 다섯 / 나 독빛 나비 떼
