## 1. 자동 사냥 중 화면 켜 두기
- 자동 사냥이 켜져 있으면 브라우저 화면 켜짐 유지(Wake Lock) 요청, 끄면 풀기. 다른 앱에서 돌아오면 다시 요청
- 지원: 아이폰 사파리 iOS 16.4+, 홈 화면 앱 iOS 18.4+, 안드로이드 크롬. 전원 버튼 · 다른 앱으로 가면 웹 게임은 멈춤 (피할 수 없음)

## 2. 절전 화면
- 메뉴 [🌙 절전 화면: 끔 / 3분 / 10분] (처음 3분, 이 기기에 저장 `hny_sleep`) · [🌙 지금 절전 화면으로] (자동 사냥 중에만)
- 자동 사냥 중 정한 시간 동안 손대지 않으면 검은 화면: 절전 시간 · 사냥터 · 레벨 · 경험치 막대 · 잡은 수 · 오른 경험치 · 골드 · 아이템 수 · 남은 HP/MP 물약 · 장비 칸 빈칸 · 경고(물약 100개 미만 · 장비 칸 가득)
- 게임은 계속 돌고 그리기만 쉼 (World.draw 건너뜀). 밀어서 풀기
- 자동 사냥이 멈추면(쓰러짐 · 물약 없음 · 보스 처치 등) 저절로 풀리고 요약에 까닭
- 풀면 "절전 중에 얻은 것": 시간 · 경험치(레벨업) · 잡은 수 · 골드 · 쓴 물약 · 아이템(등급 색, 10종까지)
