## 1. 4차 버프 모습 8종 (`src/systems/skillx.js` 의 AURA · AURA_DRAW 교체)

지금: 'lighter'(빛 더하기)로 그려서 배경에 따라 하얗게 날거나 회색으로 탁해짐 → 새 모습은 색을 직접 칠함 (밝은 · 어두운 배경 모두 또렷)

| 버프 | 결정 | 그리는 자리 |
|---|---|---|
| 천붕검제의 각성 (w4a_awake) | 달아오른 칼날 — 칼날이 붉게 달아올라 은은히 빛남 (칼끝 불꽃 없음) | 무기 |
| 불멸 (w4b_awake) | 수호 방패 문장 — 머리 위 십자 금빛 작은 방패, 숨 쉬듯 빛남 | 머리 위 |
| 천궁의 각성 (a4a_awake) | 금빛 별 활 0.6배 — 등 뒤 활 빛 고리 + 시위 자리 별 셋, **따라다님** | 등 뒤 (따라옴) |
| 저격왕의 각성 (a4b_awake) | 조준경 문장 — 머리 위 조준 표식, 눈금이 돌고 가운데 붉은 점 깜빡 (**지금은 모습 없음 → 새로 생김**) | 머리 위 |
| 화염군주의 각성 (m4a_awake) | 따라다니는 불씨 — 꼬리 달린 작은 불덩이가 허리 높이로 몸 둘레를 돎 (머리와 안 겹침) | 몸 둘레 (앞 · 뒤) |
| 현자의 각성 (m4b_awake) | 번개 고리 구름 0.5배 — 작은 먹구름 둘레를 파란 전기 고리가 돎, **따라다님** | 머리 위 (따라옴) |
| 야천의 각성 (t4a_awake) | 따라다니는 그림자 표창 — 보랏빛 표창이 빙글빙글 돌며 허리 둘레를 돎 | 몸 둘레 (앞 · 뒤) |
| 검무의 각성 (t4b_awake) | 춤추는 쌍검 — 작은 초록 칼날 두 자루가 마주 보며 허리 둘레를 돎 | 몸 둘레 (앞 · 뒤) |
| (2차 분노 w2a_rage) | 그대로 | — |

만드는 방법
- **앞 · 뒤 나눠 그리기**: 지금 `G.SkillX.aura(ctx, p)` 는 캐릭터보다 먼저(뒤) 그림. 새로 `G.SkillX.auraFront(ctx, p)` 를 `player.js` 에서 캐릭터 다음에 불러, 몸 앞으로 지나가는 불씨 · 표창 · 쌍검 · 전기 고리 앞쪽을 그림
- **무기 빛 (천붕검제)**: 공격할 때 팔이 휘두르므로 무기를 그리는 자리(`outfit.js` weapon) 안에서 칼날 위에 덧그림 → 휘두를 때도 칼날에 붙어 있음. humanoid 옵션 `wglow` 하나 추가 (없으면 지금과 똑같음)
- **따라다니기 (천궁 · 현자)**: 캐릭터마다 위치 · 속도를 하나씩 들고 스프링처럼 목표점(등 뒤 / 머리 위)으로 끌려옴, 움직이면 살짝 늦게 따라오며 기울고 멈추면 제자리. 맵을 옮기거나 순간이동하면 바로 제자리로
- 몸 둘레를 도는 것은 화염군주 · 야천 · 검무가 같은 길(허리 높이 · 너비 42)을 씀
- 다른 사람 캐릭터(마을 NPC 등)에는 나오지 않음 — 지금처럼 버프가 켜진 플레이어만

## 2. 몬스터 테두리 옅게 (나 안) (`src/render/boss_new.js` 의 `G.MonRefine`)
- 시안에서 쓴 값 `{ silA: 0.3, fade: 0.35, tint: '#c8d4f0' }` 을 기본으로: 바깥 어두운 외곽선을 30% 로 옅게 + 가장자리 2px 를 밝은 푸른빛으로 살짝 물들여 배경에 스며들게
- 대상: 다듬기(refine)가 켜진 몬스터 모두 — 일반 몬스터 54종 + 보스 8종 (녹스는 다듬기 없음 → 그대로)
- 저장해 다시 쓰는 방식(마리마다 1/30초)은 그대로 → 그리기 시간 늘어남은 작을 것. 휴대폰 화면 기준 몬스터 많은 맵에서 다시 잼 (빌드 9: 7~10ms)

## 3. 하늘 스킬 효과 7가지 (`src/systems/skillx.js` 의 FXS · PROJ)

지금: 원 몇 개를 겹친 구름, 원 + 선 해 → 진짜 구름 · 해 느낌으로

| # | 스킬 | 결정 |
|---|---|---|
| 1 | 천궁 폭풍우 (a4a_final, stormcloud) | 가: 거대한 적란운 + 비 + 갈라지는 노란 번개, 번개 칠 때 구름 속 번쩍 |
| 2 | 썬더 스톰 · 천둥 신의 분노 (m3b_thunder · m4b_final, cloud) | 가 (2차): 크고 진한 먹구름 띠 + 속 · 둘레 푸른 번쩍 + 양옆 가지 번개 |
| 3 | 태양 낙하 (m4a_final, sun) | 가: 눈부신 해 (흰 핵 → 노랑 · 주황 + 빛살 + 렌즈 빛) |
| 4 | 천공의 화살비 (a4a_rain, gate) | 가: 구름이 양옆으로 갈라지며 빛줄기가 쏟아짐 |
| 5 | 칠흑의 밤 · 야천 멸살 (t4a_dark · t4a_final, darknight) | 나: 보랏빛 달(크레이터 · 달무리) + 지나가는 얇은 구름 + 별 반짝 + 하늘 전체가 위부터 어두워짐 |
| 6 | 천둥의 심판 (m4b_judge, thunderpillar) | 나 수정: 하늘 번쩍 + 넓은 먹구름에서 번개 세 줄기 + 땅 충격 빛 |
| 7 | 떨어지는 돌 — 유성 낙하 · 태양 낙하 (PROJ meteor) | 나: 하얗게 빛나는 별똥 (빛 덩어리 + 푸른빛 꼬리 · 불씨) |

만드는 방법
- 새 파일 `src/render/skyfx.js` (skillx.js 보다 먼저 불러옴): 구름 · 번개 · 비 · 해 · 달 · 별똥 그리는 도우미 (시안 `sky_A/skyreal.js` · `skyreal2.js` 를 정리)
- **속도**: 구름은 작은 덩어리 140개를 그려 만드는 무거운 그림 → 효과가 생길 때 **한 번만 그려 저장**하고 매 프레임은 저장한 그림을 옮기기 · 투명도만 바꿈 (번쩍일 때 그림도 한 장 더 저장). 번개 모양도 번쩍일 때마다 미리 만들어 둔 몇 가지 중에서 고름
- 그대로: 데미지 · 범위 · 시간 · 효과가 나오는 위치 · 소리 · 화면 흔들림

## 4. 버그: 파라칸 3페이즈 전환 때 '태양의 심판' 안전지대가 남음 (`src/entity/boss.js` · `src/world.js`)
- 원인: HP 40% 페이즈 전환이 하던 패턴을 정리 없이 끊음 → 태양의 심판 중이면 안전지대 · 카운트("1")만 남고, 파라칸은 다시 공격 → 자동 전투가 남은 안전지대에 머물며 모래 회오리를 계속 맞고 쓰러짐
- 고침 1: 페이즈가 바뀔 때 이미 있는 정리(`cleanup`)를 불러 남은 안전지대 · 장판 · 끌어당김 · 방어 상태를 지움 (근위대 패턴 중 전환 때 방어가 안 풀리던 문제도 같이 막힘)
- 고침 2 (안전장치): 안전지대 카운트가 0을 지나 1초 넘게 남아 있으면 저절로 지움 (다른 이유로 남아도 멈추지 않게)
