## 1. 공통 그리기 도구 — 새 파일 `src/render/spellfx.js` (skyfx.js 다음, skillx.js 앞)
- **불**: 열에 따라 색이 식는 불 입자 (연노랑 → 주황 → 빨강 → 연기). 뜨거운 부분은 빛 더하기로 겹쳐 가운데가 밝게(하얀 빛은 줄인 값), 위로 길쭉한 불 혀 · 흔들림 · 위로 피어오르는 어두운 연기 · 땅에 비치는 불빛 · 꼬리 달린 불씨
- **번개**: 중간점을 흔들어 잘게 갈라지는 실제 번개 + 가지 + 빛 4겹(넓은 푸른 빛 → 흰 심), 맞은 자리 번쩍
- **얼음**: 투명한 육각 결정(테두리 빛 · 결) · 서리 안개 · 반짝임 · 땅 서리 · 깨질 때 조각
- 구름: 빌드 10 `skyfx.js` 구름을 **구름 나 다듬기 ②** (부드럽게 번지는 두 겹 · 밑면 흐림 · 가로 꼬리, 불투명 70%) 로 바꿈 → 천둥 신의 분노에 쓰고, 다음 빌드의 천궁 · 야천 하늘 구름도 이것으로
- 속도: 입자 수를 스킬마다 정해 두고(시안 기준), 그림판(그라데이션)을 미리 만들어 다시 씀. 하늘 · 큰 효과는 빌드 10처럼 같은 효과가 떠 있으면 새로 안 만듦

## 2. A 불 — 화염군주 10개 (시안 `fire3.js` · `fire3_a/b.png` · `fire3_white.png` · `fire3_pillar.png` · `fire_wheel.png`)
| 단계 | 스킬 | 새 모습 | 크기 |
|---|---|---|---|
| 2차 | 화염구 | 불꼬리 끄는 작은 불덩이 → 작게 터짐 | 작게 |
| 2차 | 화염 폭발 | 바로 앞에서 불꽃이 피었다 연기로 사그라짐 | 작게 |
| 2차 | 유성 낙하 | 작은 불타는 운석(용암 금 바위 + 불꼬리) 3~4개 | 작게 |
| 3차 | 업화 | 큰 불덩이가 적을 뚫고 지나가며 지나간 자리에 불길 | 중간 |
| 3차 | 화염 기둥 | 땅이 갈라지며 낮은 불기둥 3개(높이 160) + 연기 | 중간 |
| 3차 | 화염 고리 | 발밑에서 낮은 불길이 둥글게 퍼짐 | 중간 |
| 3차 | **화염 수레바퀴** (불꽃 폭풍 자리) | 달아오른 쇠 바퀴가 굴러가며 뒤로 불길 · 연기 · 꼬리 불똥 · 그을린 자국 | 중간 |
| 4차 | 화염군주의 창 | 불 창 2개가 꽂히고 그 자리에서 불길 | 크게 |
| 4차 | 대화재 | 앞쪽 한 구역에만 불비 + 땅이 타오름 (하늘 전체는 안 붉어짐) | 크게 |
| 궁극기 | 태양 낙하 | 하늘의 해(빌드 10) + **절반 크기** 하얀 별똥 6개 + 화면 열기 + 떨어진 자리 불길 | 가장 크게 |
- **불꽃 폭풍 → 화염 수레바퀴**: 이름 · 아이콘(`icons2.js` 새 문양: 불타는 바퀴) · 설명만 바꿈. id `m3a_storm` · 데미지 · 범위 · 화상 그대로 → 배운 레벨 그대로. 바퀴는 지금 맞히는 범위 안에서 앞으로 굴러감
- 유성 낙하의 떨어지는 돌(발사체 meteor)은 유성 낙하 = 불타는 운석, 태양 낙하 = 작은 하얀 별똥으로 나눔

## 3. B 얼음 · 번개 — 천둥의 현자 10개 (시안 `ice.js` · `ice_a/b.png` · `ice_fix.png` · `ice_beam3.png` · `sage_final.png`)
| 단계 | 스킬 | 새 모습 |
|---|---|---|
| 2차 | 냉기 광선 | **다 서리 바람**: 땅을 따라 낮게 차가운 바람이 쓸고 지나가며 땅이 얼고 눈가루 · 맞은 적 발밑 얼음 |
| 2차 | 얼음 파편 | 투명한 얼음 결정 3개 · 서리 꼬리 · 맞으면 깨져 흩어짐 |
| 2차 | 연쇄 번개 | 지팡이 → 첫 적 → 다음 적으로 튕기는 실제 번개 |
| 3차 | 썬더 스톰 | 구름 · 세로 빛줄기 없이, 전기가 튀는 번개 구슬 8개 → 땅에서 번쩍 |
| 3차 | 낙뢰 | 적 머리 위 푸른 표식 → 하늘 끝에서 실제 번개가 한 마리씩 꽂힘 |
| 3차 | 빙결 폭발 | 발밑에서 서리가 퍼지며 땅에서 투명한 얼음 가시 · 차가운 안개 |
| 3차 | 얼음 창 | **나 땅에서 솟는 얼음 창**: 적 발밑이 얼며 고드름 같은 얼음 창 여러 개가 솟아 꿰뚫고 부서짐 |
| 4차 | 천둥의 심판 | 하늘에 옅게 빛나는 마법진 → 실제 번개가 비스듬히 연달아 꽂힘 |
| 4차 | 절대 영도 | 하얀 냉기 물결이 퍼지며 땅이 얼고 적들이 얼음에 갇힘 |
| 궁극기 | 천둥 신의 분노 | 넓은 뇌운(구름 나 다듬기 ②) + 번개 다섯 줄기(가운데 굵게) + 화면 번쩍 + 땅 충격 + 적 사이 튕기는 번개 |
- 얼음 창 · 냉기 광선은 지금 "앞으로 날아가는 발사체"라, 그림만 바꿀 때 맞히는 방식은 그대로 두고 **날아가는 자리에서 그 모습이 나타나게** 함 (얼음 창: 발사체가 닿는 적 발밑에서 솟음 · 냉기 광선: 발사체가 지나는 길 땅 위로 서리 바람)

## 4. 고치는 파일
- 새 `src/render/spellfx.js` (index.html 에 skyfx.js 다음 한 줄)
