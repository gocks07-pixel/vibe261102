## A. 스킬 렉 줄이기 — 고치는 5가지

### 1. 몬스터 색 필터를 한 번만 (시안에서 측정 완료)
- 원인: 맞을 때 번쩍 · 얼음 · 열기 · 기술 예고 번쩍 · 그림자 분신(도적 버프)이 `ctx.filter` 를 켠 채 몬스터의 선 · 도형을 하나하나 그림 → 사람 모양 몬스터는 한 마리에 수백 번 필터. 휴대폰(특히 아이폰 사파리)에서 아주 느림
- `src/render/sprites.js`: 새 `G.Draw.fLayer` — 몬스터를 작은 그림판 한 장에 그린 뒤 화면에 한 번만 찍음. 필터도 쓰지 않음
  - 번쩍: 같은 그림을 빛 더하기로 한 번 더 · 얼음: 푸른색 덮기 · 열기: 주황색 덮기 · 그림자 분신: 짙은 보라 덮기 (모습은 시안 비교처럼 같음)
- 고치는 곳: `sprites.js` 몬스터 그리기(맞을 때), `src/entity/monster.js` draw(얼음 · 열기 · 예고), `src/systems/skillx.js` 그림자 분신

### 2. 쓰러지는 몬스터 (시안에서 측정 완료)
- `src/render/boss_new.js`: 다듬은 그림을 쓰러질 때도 매 장면 → 1/30초마다 새로 만듦. 계산용 그림판은 크기를 바꾸지 않고 커지기만 함

### 3. 자동 품질 조절 (새로)
- 새 파일 `src/systems/perf.js` (`G.Perf`): 실제 화면 시간(1초 평균)을 재서
  - 느려짐(평균 22ms 넘음, 1초 동안) → **낮춤**: 불 · 연기 · 빛 입자 수 절반(`G.Settings.fxMul` 에 곱함), 화면 전체 열기 · 번쩍은 옅게 한 번만
  - 다시 빨라짐(평균 17ms 아래, 3초 동안) → **보통**으로 돌아감
- 설정 창의 "이펙트 강도" 저장 값은 그대로 (자동으로 바뀌는 건 저장 안 함). 빠른 기기는 계속 보통
- 고친 뒤에도 무거웠던 스킬은 효과 자체를 다시 봄: 천궁 폭풍우 · 천상의 심판 · 성역 · 멸천 낙화 · 대화재 · 화염 고리 → 입자 수 상한, 겹치는 빛 층 줄이기 (모습은 시안 기준 유지)

### 4. 처음 쓸 때 멈칫 없애기
- 맵에 들어갈 때(`changeMap` 뒤 잠깐 쉬는 동안) 내 직업 스킬이 쓰는 그림 재료를 미리 만듦: 빛 · 연기 스프라이트(spellfx), 하늘 구름 · 해 · 달(`G.SkyFX.prewarm`), 버프 모습(aura10)

### 5. 큰 스킬 중 장비 효과 쉬기
- `src/render/gearfx.js`: 자동 품질이 **낮춤**이거나 큰 스킬 효과가 떠 있는 동안(1~2초)은 장비 빛 · 결을 빼고 원래 그림으로. 끝나면 다시 켜짐

## B. 미니맵 퀘스트 표시 — 다 안 (`src/world.js` drawMinimap)

- **미니맵 위**: 퀘스트가 있는 NPC 점 → 작은 동그라미(시안 60% 크기) — 노랑 ! 메인 받기 · 파랑 ! 서브 받기 · 초록 ? 완료 보고 (NPC 머리 위 표시와 같은 `G.Quest.marker`). 퀘스트 없는 NPC 는 흐린 점
- **미니맵 아래 할 일 줄** (줄인 크기: 높이 15 · 글자 10 · 폭 미니맵의 82%), 최대 4줄
  - 순서: 완료 보고(?) → 메인 받기 → 서브 받기, 같은 맵 먼저
  - 글: "하르몬에게 완료 보고" · "미나 · 서브 받기" · "토르 · 메인 받기"
  - **다른 맵에 있는 NPC**: 오른쪽에 맵 이름과 방향 "바람결 마을 ▶" (길 안내 `G.Nav.npcMap` · `G.Nav.route` 의 첫 출구 방향으로 ◀ / ▶). 미니맵 가장자리에도 그쪽 화살표 + 표시
  - 할 일이 없으면 줄 없음
- 목록은 0.5초마다 다시 계산(매 장면 계산 안 함). 미니맵을 끄면(설정) 같이 꺼짐
- 휴대폰: 미니맵 아래가 버튼 · 상태창과 겹치지 않는지 아이폰 SE · 13 · 갤럭시 화면으로 확인

## C. 확인
- 속도: 시안과 같은 방법(아이폰 13 가로 크기 · 매 장면 그리기 끝까지)으로 8직업 3·4차·궁극기 스킬 **지금 시험판 / 새 판** 비교표 + 자동 품질이 켜지는 순간 화면
- 모습: 맞을 때 번쩍 · 얼음 · 열기 · 그림자 분신 · 쓰러짐 전후 비교, 자동 품질 보통 / 낮춤 비교
- 미니맵: 새싹항 · 바람결 마을 · 라그하르트에서 표시 · 할 일 줄 · 다른 맵 방향, 퀘스트를 받고 · 완료하면 바로 바뀌는지
- `questgo_move.js` · 완주 4명(마법사 포함) · 오류 0 → 커밋 · 시험판 → "배포해 줘" 받으면 정식 배포 · EXE 대화창 글 (빌드 11 전체)
