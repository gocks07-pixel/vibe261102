- 7초 → **3분** (처치한 때부터). 사냥터에 처음 들어오면 **30초 뒤** 첫 출현
- 미니맵 왼쪽 위에 다음 출현까지 남은 시간 "👑 2:41" (출현 중이면 왕관 표시만)

- 원하면 시간 조절 가능 (예: 2분 · 5분)

## 2. 가 별빛 결계 출현
- 높은 발판 대신 **넓은 땅**(플레이어에게서 떨어진 쪽)에 하늘 빛기둥과 함께 나타남 (1초 연출 동안은 맞지 않음)
- 둘레에 둥근 빛 결계(반지름 250) — 정예는 결계 밖으로 나가지 않고 그 안에서 싸움. 결계 안 일반 몬스터는 밖으로 밀려남(겹쳐서 헷갈리지 않게)
- 화면 위 알림 "★ 정예 출현! ○○" · 미니맵 왕관 · 소리
- 높은 발판과 보물 상자는 그대로 (2단 점프로 올라가는 보물 자리)

## 3. 나 정예마다 고유 패턴 1개 (피하면 약점 노출 4초 · 받는 피해 +50%)
- 8초쯤마다, 바닥에 빨간 표시 2초 → 공격. 표시를 피해 맞지 않으면 정예가 휘청 · 머리 위 "약점 노출!"
| 정예 | 패턴 |
|---|---|
| 광석 거인 | 땅 내려찍기: 결계 안 바닥 세 줄 균열 표시 → 바위가 솟음 |
| 사막 전갈왕 | 꼬리 독침: 앞쪽 부채꼴 표시 → 꼬리가 땅에 박혀 휘청 |
| 서리비늘 골렘 | 얼음 고리: 몸 둘레 고리 표시(안쪽 위험 · 바깥 안전) → 얼음 가시 |
| 뇌운 거인 | 낙뢰: 바닥 번개 표시 3곳 → 번개 (시안 그림) |
| 그림자 집행관 | 십자 베기: 플레이어 자리에 십자 표시 → 순간이동 베기 |
- 패턴 피해는 원래 몬스터 스킬 피해와 비슷한 크기 (정예 공격력 기준). 자동 사냥 · 자동 보스는 표시 밖으로 피함 (기존 예고 피하기와 같은 방식)
