# 빌드 1.9 계획: 복장·장비 모양 (승인됨 · 구현 대기)

2026-11-04 확정. 사용자가 "1.9 진행해 줘"라고 요청하면 구현한다. 1.8 다음, EXE 빌드 전.
장비 능력치·이름·드롭은 바꾸지 않는다. 캐릭터 겉모습만 바꾼다.

## 지금 상태 (1.4)
- 캐릭터 만들기의 복장 4종(선원 복장, 여행자 복장, 견습생 로브, 캐주얼)은 상의·하의 색 2개만 다르고 모양은 같다
- 장비를 입으면 옷 색만 장비 색으로 바뀐다 (모양은 그대로)

## 1. 복장 4종 전용 디자인
- 선원 복장: 세일러 칼라, 줄무늬 상의, 넓은 바지
- 여행자 복장: 짧은 망토, 허리 가방 벨트, 부츠
- 견습생 로브: 발목까지 오는 긴 로브, 넓은 소매, 허리끈
- 캐주얼: 후드티, 반바지, 운동화

## 2. 장비 모양
- 모자·상의·하의·신발·장갑·망토·무기가 색뿐 아니라 모양도 보이게 한다 (투구, 갑옷, 로브, 망토 등)
- 장비 등급·세트(라그 강철, 사하린 왕조, 서리용, 천공, 별조각 계승자 등)마다 알아볼 수 있는 디자인
- 이미지 파일 없이 코드로 그린다. 다른 게임의 디자인은 가져오지 않는다
- 캐릭터 만들기 미리보기, 장비창, NPC 모습에도 같은 그리기 코드를 쓴다

## 3. 확인 방법
- 복장·장비 세트를 전부 입혀 본 캐릭터를 나란히 그린 확인용 페이지를 만들어 사용자에게 보여 준다
