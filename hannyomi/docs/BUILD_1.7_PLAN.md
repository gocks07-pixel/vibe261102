# 빌드 1.7 계획: 몬스터 전용 생김새 후반부 (구현 완료 · 2026-11-04)

2026-11-03 확정. 사용자가 "1.7 진행해 줘"라고 요청하면 구현한다. 1.6 다음, 1.8 전.
스토리·퀘스트·전투 수치는 바꾸지 않는다. 몬스터의 생김새와 움직임을 바꾸고, 하단 상태창 높이를 줄인다.

## 공통 원칙 (1.6 / 1.7)
- 지금은 "모양" 16종을 색·크기만 바꿔 70종이 같이 쓴다. 몬스터마다 **전용 그림 + 전용 움직임**(걷기·공격·피격·쓰러짐)으로 바꾼다
- 이미지 파일 없이 코드로 그린다. 다른 게임의 디자인은 가져오지 않고 직접 디자인한다
- 사용자가 참고로 준 링크(메이플 인벤 몬스터 도감)는 "몬스터 종류가 다양한 게임" 참고용일 뿐, 디자인을 보거나 가져오지 않는다
- 몬스터 이름·능력치·드롭은 그대로. 히트박스(가로·세로 크기)도 되도록 유지해서 전투 감각이 바뀌지 않게 한다
- 완성 후 몬스터 도감처럼 전부 나란히 그린 확인용 페이지를 만들어 사용자에게 보여 준다

## 1.6에서 만든 구조 (이어서 쓰기)
- `src/render/monsters2.js`에 `A(몬스터 id, 쓰러지는 방식, 그림자 배율, 그리기 함수)`로 등록 (1.6 32종과 같은 방식)
- 쓰러지는 방식: flip(뒤집힘) / melt(녹아내림) / fall(추락, 나는 몬스터) / crumble(부서짐) / pop(터짐)
- 그리기 함수의 s = { walk, atk, hurt, die, t }. 보스는 m.boss.raise(패턴 예고), m.boss.cur, m.boss.phase, m.groggy 등으로 상태 표현
- 녹스는 이미 전용 그림이 있어 1.7에서는 다듬기만 한다. 확인용 몬스터 도감 페이지도 1.7 몬스터까지 넣어 다시 공유
