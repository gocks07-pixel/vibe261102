# 빌드 1.6 계획: 몬스터 전용 생김새 전반부 (구현 완료 · 2026-11-04)

2026-11-03 확정. 사용자가 "1.6 진행해 줘"라고 요청하면 구현한다. 1.5 다음, 1.7 전.
스토리·퀘스트·전투 수치는 바꾸지 않는다. 몬스터의 생김새와 움직임만 바꾼다.

## 공통 원칙 (1.6 / 1.7)
- 지금은 "모양" 16종을 색·크기만 바꿔 70종이 같이 쓴다. 몬스터마다 **전용 그림 + 전용 움직임**(걷기·공격·피격·쓰러짐)으로 바꾼다
- 이미지 파일 없이 코드로 그린다. 다른 게임의 디자인은 가져오지 않고 직접 디자인한다
- 사용자가 참고로 준 링크(메이플 인벤 몬스터 도감)는 "몬스터 종류가 다양한 게임" 참고용일 뿐, 디자인을 보거나 가져오지 않는다
- 몬스터 이름·능력치·드롭은 그대로. 히트박스(가로·세로 크기)도 되도록 유지해서 전투 감각이 바뀌지 않게 한다
- 완성 후 몬스터 도감처럼 전부 나란히 그린 확인용 페이지를 만들어 사용자에게 보여 준다
