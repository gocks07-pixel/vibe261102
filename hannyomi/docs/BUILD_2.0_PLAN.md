# 빌드 2.0 계획: 히든 엔딩 "공명 · 함께 빛나는 별" + 타이틀 화면 (승인 대기)

2026-11-04 히든 엔딩 확정, 2026-11-05 영상 주인공 · 타이틀 화면 · 게임 이름 · 연희 모습 추가.
사용자가 "2.0 진행해 줘"라고 요청하면 구현한다. 1.9 다음, EXE 빌드 전.
기존 엔딩 2개(희생 · 영원한 별 / 구원 · 새로운 별)와 진행 루트는 그대로 둔다. 아이템 id · 세이브 형식도 그대로 (기존 세이브 유지).

## 1. 히든 엔딩 기본 구조
- 루트는 하나. 마지막 퀘스트 "별의 선택"(f_08)에서 엔딩을 고른다
- 조건을 다 채웠을 때: 버튼 3개 — 희생 / 구원 / **함께 빛난다 (공명)** ← 금색 버튼
- 조건을 못 채웠을 때: 지금처럼 버튼 2개 (희생 / 구원)

## 2. 열리는 조건 (서브 퀘스트 6개)
- 카이엔의 이야기: 검사의 수련(c2_s4) → 교단의 문장(c3_s4) → 카이엔의 과거(c6_s3)
- 엘마 할머니의 기록: 할머니의 기록(f_s2)
- 영웅들의 이야기: 일곱 영웅의 이름(c4_s4) → 영웅들의 마지막 부탁(f_s4)
- "모든 서브 퀘스트 완료"는 조건에 넣지 않는다

## 3. 놓치지 않게 하는 장치
- 조건 퀘스트를 하나 완료할 때마다 손등 문양이 빛나고 "무언가가 공명한다..." 메시지
- 마지막 퀘스트 직전, 조건을 못 채웠으면 엘마가 "아직 당신을 기다리는 사람들이 있는 것 같아요..."라고 귀띔

## 4. 희생 · 구원 엔딩을 봤을 때
- 크레딧 뒤 안내 화면: "✦ 별조각들이 아직 무언가를 기다리고 있습니다... 이 이야기에는 숨겨진 또 하나의 결말이 있습니다."
  - [히든 엔딩을 찾아 계속하기] → 계속 플레이 + 못 채운 조건을 **힌트로만** 알려 줌 (퀘스트 이름 · 위치는 알려 주지 않음)
    - 힌트 예: "카이엔이 아직 하지 못한 이야기가 있다", "엘마의 할머니가 남긴 기록이 흩어져 있다", "일곱 영웅의 이름이 모래 속에 잠들어 있다"
    - 힌트는 녹스게이트의 엘마에게 말을 걸어 다시 볼 수 있다
  - [그냥 계속 플레이] → 평소처럼 계속 플레이 (힌트 없음)
  - 어느 쪽이든 나중에 조건을 채우면 언제든 히든 엔딩을 볼 수 있다
- 조건을 이미 다 채웠는데 희생/구원을 고른 경우: 안내 화면 대신 "엘마에게 가면 다른 결말을 볼 수 있다"고 짧게 알림

## 5. 엔딩 뒤 히든 엔딩으로 넘어가기
- 엔딩 직후 문구: "하지만 별조각들은 그 선택의 순간을 아직 기억하고 있었다..."
- 조건을 채우고 녹스게이트의 엘마에게 말하면, 별조각의 기억으로 선택의 순간으로 돌아가 "함께 빛난다"를 고를 수 있다

## 6. 히든 엔딩 내용
- 주인공이 별빛을 혼자 바치지 않고 엘마(영웅의 피) · 카이엔(교단에서 돌아온 자) · 일곱 영웅의 잔영과 나눈다
- 녹스는 500년의 외로움에서 풀려나 처음으로 "별"이 되고, 아무도 사라지지 않는다. 일곱 영웅의 잔영은 그제야 잠든다
- 영상 5장면 (1.7.7에 준비됨, `G.SCENES.hidden`): 공명 → 처음으로, 별이 되다 → 잠드는 영웅들 → 등대와 등불 → 새싹항 바닷가
- 전용 음악: 메인 테마를 오르골 + 현악으로 따뜻하게 편곡 (`G.Cutscene.MUSIC.hidden`)
- 세이브 슬롯 카드에 "★ 히든 엔딩 클리어" 따로 표시
- 테스트 모드의 엔딩 미리보기, 타이틀의 "이야기 다시 보기"에 히든 엔딩 추가

## 7. 영상 속 주인공 외형
| 영상 | 주인공 |
|---|---|
| 배경 설명 (intro) | **연희 외형** (어떤 캐릭터로 플레이하든, 타이틀에서 다시 볼 때도) |
| 히든 엔딩 (hidden) | **연희 외형** (예전 장면들이 나오므로) |
| 희생 · 구원 엔딩 | 지금 그대로 (플레이어 캐릭터의 외형 · 눈 · 장비) |

- 구현: `G.Cutscene.play`에서 kind가 intro · hidden이면 주인공을 연희 NPC와 같은 외형 데이터로 그림 (NPC 외형을 바꾸면 영상도 같이 바뀜)

## 8. 연희 모습 수정
- 연희 NPC 데이터에 성별이 빠져 있어 머리만 길고 바지 · 속눈썹 없음으로 그려짐 → **여자로 지정 (치마 + 속눈썹)**
- 갈색 긴 생머리 · 하늘색 상의 · 파란 치마 · 갈색 눈
- 적용되는 곳: 라그하르트 · 녹스게이트 연희 NPC, 대화창 초상화, 배경 설명 · 히든 엔딩 영상, 타이틀 화면

## 9. 타이틀 화면
- 시안: https://claude.ai/artifact/LJVHDLSRtoYBuvtsDj64gc
- 제목 두 줄: 윗줄 작게 "과금없이 즐기는" / 아랫줄 크게 "연희의 RPG 대모험! ✦" (금색→분홍 그라데이션, 보라 그림자, 살짝 둥실) / 아래 작게 "아르셀리아 연대기" (버전 표시는 뺌)
- 글씨체: **주아(Jua)**, SIL OFL 무료 글꼴. EXE는 인터넷 없이 실행될 수 있으므로 글꼴 파일을 게임 폴더(`css/fonts/`)에 넣어 함께 배포
- 배경 (시안 그대로, 천천히 움직임):
  - 반짝이는 별, 가끔 떨어지는 별조각 (이야기의 시작)
  - 일곱 개의 별을 이은 별자리 (일곱 영웅)
  - 먼 하늘의 은은한 등불 (녹스, 히든 엔딩 복선)
  - 새싹항 바다와 등대, 불빛이 천천히 회전
  - 바닷가에서 별을 올려다보는 연희
- 버튼(이어하기 · 새로 시작 · 테스트 모드 · 조작법 · 음악 감상 · 이야기 다시 보기 · 배경음/효과음)은 지금 위치 그대로 위에 얹음
- 시스템의 "움직임 줄이기" 설정이 켜져 있으면 배경을 멈춘 그림으로
