기존 엔딩 2개(희생 · 영원한 별 / 구원 · 새로운 별)와 진행 루트는 그대로 둔다.

## 1. 기본 구조
- 루트는 하나. 마지막 퀘스트 "별의 선택"(f_08)에서 엔딩을 고른다
- 조건을 다 채웠을 때: 버튼 3개 — 희생 / 구원 / **함께 빛난다 (공명)** ← 금색 버튼
- 조건을 못 채웠을 때: 지금처럼 버튼 2개 (희생 / 구원)

## 2. 열리는 조건 (1.5 서브 퀘스트 6개)
- 카이엔의 이야기: 검사의 수련(c2_s4) → 교단의 문장(c3_s4) → 카이엔의 과거(c6_s3)
- 엘마 할머니의 기록: 할머니의 기록(f_s2)
- 영웅들의 이야기: 일곱 영웅의 이름(c4_s4) → 영웅들의 마지막 부탁(f_s4)
- "모든 서브 퀘스트 완료"는 조건에 넣지 않는다 (2026-11-04 사용자 결정)

## 3. 놓치지 않게 하는 장치
- 조건 퀘스트를 하나 완료할 때마다 손등 문양이 빛나고 "무언가가 공명한다..." 메시지
- 마지막 퀘스트 직전 엘마가 "아직 당신을 기다리는 사람들이 있는 것 같아요..."라고 귀띔 (조건을 못 채웠을 때)

## 4. 엔딩 2개 중 하나를 봤을 때
- 크레딧 뒤 안내 화면: "✦ 별조각들이 아직 무언가를 기다리고 있습니다... 이 이야기에는 숨겨진 또 하나의 결말이 있습니다."
  - [히든 엔딩을 찾아 계속하기] → 계속 플레이 + 못 채운 조건을 **힌트로만** 알려 줌 (퀘스트 이름·위치는 알려 주지 않음)
    - 힌트 예: "카이엔이 아직 하지 못한 이야기가 있다", "엘마의 할머니가 남긴 기록이 흩어져 있다", "일곱 영웅의 이름이 모래 속에 잠들어 있다"
    - 힌트는 나중에 녹스게이트의 엘마에게 말을 걸어도 다시 볼 수 있다
  - [그냥 계속 플레이] → 평소처럼 계속 플레이 (힌트 없음)
  - 어느 쪽을 골라도 계속 플레이할 수 있고, 나중에 조건을 채우면 언제든 히든 엔딩을 볼 수 있다
- 조건을 이미 다 채웠는데 희생/구원을 고른 경우: 안내 화면 대신 "엘마에게 가면 다른 결말을 볼 수 있다"고 짧게 알림

## 5. 엔딩 뒤 히든 엔딩으로 넘어갈 때 (이야기 연결)
- 엔딩 직후 문구: "하지만 별조각들은 그 선택의 순간을 아직 기억하고 있었다..."
- 조건을 채우고 녹스게이트의 엘마에게 말하면, 별조각의 기억으로 선택의 순간으로 돌아가 "함께 빛난다"를 고를 수 있다

## 6. 히든 엔딩 내용
- 주인공이 별빛을 혼자 바치지 않고 엘마(영웅의 피)·카이엔(교단에서 돌아온 자)·일곱 영웅의 잔영과 나눈다
- 녹스는 500년의 외로움에서 풀려나 처음으로 "별"이 되고, 아무도 사라지지 않는다. 일곱 영웅의 잔영은 그제야 잠든다
- 마지막 장면: 게임을 시작한 새싹항 바닷가에서 주인공·엘마·카이엔이 새로 태어난 별을 올려다본다
- 전용 음악: 메인 테마를 오르골 + 현악으로 따뜻하게 편곡
- 세이브 슬롯 카드에 "★ 히든 엔딩 클리어" 따로 표시
- 테스트 모드의 엔딩 미리보기에도 히든 엔딩 추가

## 7. 영상 속 주인공 외형 (2026-11-05 사용자 결정)
- 지금(1.7.7~1.9)은 모든 영상의 주인공을 플레이어가 만든 캐릭터의 실제 외형·장비로 그린다
- **배경 설명 영상(intro)**: 주인공을 **연희 NPC와 같은 외형**으로 그린다 (갈색 긴 생머리 · 하늘색 상의 · 파란 하의 · 갈색 눈, `world2.js`의 `YEONHEE`). 어떤 캐릭터로 플레이하든, 타이틀 화면에서 다시 볼 때도 같다
- **히든 엔딩 영상(hidden)**: 예전 장면들이 나오므로 주인공을 **연희 외형**으로 그린다
- **희생 엔딩(seal) · 구원 엔딩(purify)**: 지금 그대로 (플레이어 캐릭터의 외형·눈·장비)
- 구현 방법: `G.Cutscene.play(kind, done, opt)`에서 kind가 intro · hidden이면 `heroOpt`를 연희 외형으로 지정 (연희 NPC 외형을 바꾸면 영상도 같이 바뀌게 같은 데이터를 씀)
