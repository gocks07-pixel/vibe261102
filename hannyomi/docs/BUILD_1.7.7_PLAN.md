## 1. 녹스의 정체 (이야기에 넣는 설정)
- 녹스 = **"별들 사이의 밤"**. 별을 빛나게 했지만 아무도 바라봐 주지 않아, 별을 삼키면 자신도 빛날 거라 믿게 된 존재
- **공허의 별조각** = 영웅들이 녹스 가슴에서 떼어 낸 "별이 되고 싶던 마음". 그래서 봉인이 불완전했고 여덟 번째 별(주인공)이 필요했다

## 2. 디자인 (최종 후보: v3 + 두 꺼진 별 구체 · 퍼지는 금 + 꺼진 등불)
| 페이즈 | 감정 | 모습 |
|---|---|---|
| 1 봉인된 모습 (100~66%) | 체념 | 사슬에 묶여 고개 숙임, 늘어뜨린 손에 꺼진 등불, 두 꺼진 별 구체는 발치에, 가슴 별 모양 빈자리에서 짧은 금 |
| 2 각성 (66~33%) | 서러움 | 사슬이 사라지고 고개를 듦, 주인공 쪽으로 등불을 내밂, 두 구체가 떠올라 맴돎, 금이 어깨까지 |
| 3 진정한 모습 (33% 이하) | 절망 | 하체가 연기로 풀려 떠오름, 금이 온몸에, 두 구체가 빈자리로 끌려 듦, 갈라진 등불 속 별이 깜빡임 |
- 색: 검은 남색 + 차가운 별빛 (보라 네온 없음). 크기는 지금(150×?)과 비슷한 보스 크기로, 페이즈가 바뀔 때 모습이 바뀐다 (`boss.phase`로 그림 분기)
- 페이즈 전환 연출: 짧은 어두워짐 + 녹스 대사 배너 (빨간 예고와 별개)

| 때 | 대사 |
|---|---|
| 등장 (1페이즈) | "…또 별이 왔구나. 오백 년 만이다." |

| 3페이즈 | "삼켜도, 삼켜도… 왜 나는 빛나지 않는가." (기존 "이 세계의 별을 전부 삼켜 주마!" 교체) |
| 쓰러질 때 (새로) | "…따뜻하구나. 이것이… 별빛인가." |

## 4. 쓰러질 때 등불 연출 (약 3초, 임팩트 없이 밝기만)
1. 빛이 건너옴: 무릎 꿇은 녹스가 꺼진 등불을 내밂 → 주인공에게서 금빛 별가루가 등불로 날아감
2. 켜지는 순간: 등불 안의 별에 불이 붙고 은은한 금빛이 천천히 번짐 (섬광·빛살 없음)
3. 처음으로 빛나는 녹스: 몸의 금이 보라 → 금빛, 가슴 빈자리와 두 구체에 빛이 차오름 → 대사 → 기존 승리 화면·엔딩 선택
- 엔딩 문구 연결: 구원 엔딩에 "켜진 등불" 한 줄, 희생 엔딩에 "등불은 꺼진 채" 한 줄 추가 (2.0 히든 엔딩: 엘마의 등대와 녹스의 등불이 나란히 켜짐 — 2.0 계획서에 메모)
