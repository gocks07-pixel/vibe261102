# EXE 만들기 안내 (Windows PC)

EXE는 Windows 도구가 필요해서 클라우드가 아니라 **HC님 Windows PC**에서 만듭니다.
처음 한 번만 준비하면, 그다음부터는 명령 두세 줄이면 됩니다.

---

## 1. 처음 한 번만: 준비

### ① Node.js 설치
1. https://nodejs.org 에 들어갑니다.
2. **LTS**라고 적힌 버튼을 눌러 받고, 설치 화면에서 계속 "Next"만 누릅니다.
3. 설치가 끝나면 PC를 한 번 다시 켜 줍니다.

### ② 게임 원본 받기
1. https://github.com/gocks07-pixel/vibe261102 에 들어갑니다. (로그인 필요)
2. 왼쪽 위 브랜치 버튼(main)을 눌러 **hannyomi-backup**을 고릅니다.
3. 초록색 **Code** 버튼 → **Download ZIP**을 누릅니다.
4. 받은 ZIP을 원하는 곳에 풀어 줍니다. 예: `바탕 화면\vibe261102-hannyomi-backup`
5. 그 안의 **hannyomi** 폴더가 게임 원본입니다.

### ③ 명령 창 열기
1. 파일 탐색기에서 **hannyomi** 폴더를 엽니다.
2. 위쪽 주소창을 한 번 누르고 `cmd` 라고 쓴 다음 Enter.
3. 검은 창(명령 프롬프트)이 열리면 성공입니다.

### ④ 빌드 도구 설치 (처음 한 번, 몇 분 걸림)
```
npm install
```

---

## 2. 매번: EXE 만들기

검은 창에서 아래 중 하나를 입력합니다.

**플레이어용** (연희와 다른 사람에게 줄 것 · 테스트 모드 없음)
```
npm run build:player
```

**테스트용** (HC님 확인용 · 테스트 모드 있음)
```
npm run build:dev
```

끝나면 **hannyomi\dist** 폴더에 EXE가 생깁니다.

| 명령 | 만들어지는 파일 |
|---|---|
| `npm run build:player` | `RPG Adventure 2.1.7.exe` |
| `npm run build:dev` | `RPG Adventure DEV 2.1.7.exe` |

- 설치가 필요 없는 EXE입니다. 더블클릭하면 바로 실행됩니다.
- 처음 실행할 때 Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르면 됩니다. (인증서를 사지 않은 개인 프로그램이라 나오는 안내입니다)
- 빌드 전에 게임을 창으로 바로 확인하고 싶으면 `npm start` (테스트용으로 실행됩니다)

## 3. 저장 위치 (EXE를 바꿔도 지워지지 않음)

```
문서\RPG Adventure\
   ├ Save Data\          ← 플레이어용 세이브 (save_A · B · C.json)
   ├ Save Data (DEV)\    ← 테스트용 세이브
   ├ 오류기록.txt         ← 오류가 나면 자동으로 기록
   └ 버그신고\            ← 🐞 버그 신고 파일
```

- 세이브는 EXE 바깥(문서 폴더)에 있어서, **새 버전 EXE로 바꿔도 그대로** 이어서 할 수 있습니다.
- 테스트용과 플레이어용은 세이브 폴더가 달라서, 같은 PC에서 테스트해도 연희의 세이브는 안전합니다.
- 혹시 옛 위치(`문서\Hannyomi`)에 세이브가 있으면, 플레이어용을 처음 켤 때 새 위치로 자동 복사합니다. (옛 폴더는 지우지 않음)

## 4. 버그를 고쳐서 다시 주는 방법

### 플레이어
1. 게임에서 이상한 일이 생기면 **F9** (또는 Esc 메뉴 → 🐞 버그 신고).
2. "무슨 일이 있었나요?"에 짧게 적고 (안 적어도 됨) **신고 파일 만들기**.
3. 폴더가 저절로 열립니다. 그 안의 파일 5개를 카톡이나 메일로 HC님에게 보냅니다.
   - 신고내용.txt · 게임정보.txt · 오류기록.txt · 화면.png · save_X.json
   - 인터넷으로 자동 전송하지 않습니다. PC 사용자 이름 같은 개인정보는 들어가지 않습니다.

### HC님
1. 새 Claude 세션을 열고 저장소 `gocks07-pixel/vibe261102`, 브랜치 `hannyomi-backup`을 고릅니다.
2. 받은 파일들을 올리고 **"버그 고쳐 줘"** 라고 말합니다.
3. Claude가 고치고, 버전을 올리고(예: 2.1.0 → 2.1.1), GitHub에 백업합니다.
4. 위 **1-②**처럼 새 원본 ZIP을 받아 풀고, **2**처럼 `npm install` → `npm run build:player`.
   (새 폴더에 풀었다면 `npm install`을 한 번 더 해야 합니다)
5. 새 EXE를 플레이어에게 보냅니다. 플레이어는 **EXE 파일만 바꾸면** 됩니다. 세이브는 그대로입니다.

## 5. 안 될 때

| 증상 | 해결 |
|---|---|
| `'npm'은(는) 내부 또는 외부 명령...이 아닙니다` | Node.js 설치 후 PC를 다시 켜고, 명령 창을 새로 엽니다 |
| `npm install` 중 빨간 글씨 | 인터넷 연결 확인 후 다시 `npm install` |
| 빌드 중 `EPERM` · `파일을 사용 중` | 실행 중인 RPG Adventure EXE를 끄고 다시 빌드 |
| 백신이 EXE를 막음 | 백신의 "예외" 또는 "허용"에 dist 폴더를 추가 |
| 그 밖의 오류 | 검은 창의 마지막 20줄쯤을 복사해서 Claude에게 보여 주세요 |
