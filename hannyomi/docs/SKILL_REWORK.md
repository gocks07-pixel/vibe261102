- 공통(돌 던지기·응급 처치·2단 점프) 제외 아이콘 전부 다르게, 눈 아이콘 사용 금지
- 새로 만들 효과: 화상 · 빙결 · 표식 · 튕기는/돌아오는 투사체 · 바닥 장판 · 지연 폭발 · 조준선 · 분신·떠다니는 칼날 (기절·둔화·독은 이미 있음)
