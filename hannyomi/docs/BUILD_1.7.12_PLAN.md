| 반복 | 불가. 처음 완료할 때 1회만 |

### 처치 기록 (받기 전에 잡은 정예도 인정)
- 1.7.12부터 정예를 쓰러뜨릴 때마다 퀘스트와 상관없이 기록 (`p.d.flags['elite:몬스터 id'] = 1`)
- 퀘스트를 받는 순간 기록을 확인해 이미 잡은 정예는 ✔로 시작. 6종을 모두 잡았으면 받자마자 완료 가능
- **1.7.12 업데이트 전에 잡은 정예는 기록이 없으므로** 기존 세이브는 그 정예만 다시 잡으면 됨 (정예는 각 사냥터에 다시 나오고, 강해지지 않음)
- 퀘스트 목록 · 추적기에 정예 6줄 ✔/○ 표시. 길 안내(🧭)는 아직 안 잡은 정예가 있는 사냥터로

## 4. 세트 고르는 창 (새 창)
- 아스트라에게 완료하면 바로 열림. **두 개를 다 고르기 전에 닫으면** 다음에 아스트라에게 말을 걸 때 다시 열림 (`p.d.flags.heroPick` = 남은 개수)
- 두 탭: **별조각 계승자 세트 (Lv.90)** · **천공 세트 (Lv.85)**. 탭마다 7부위(방어구 6 + **자기 직업 무기만**)와 세트 효과 표(2~7부위)
- 이미 가진 부위(인벤토리 · 창고 · 착용)는 "보유" 표시 (골라도 됨). 섞어서 고르기 가능, 같은 부위 2개도 가능
- 고를 때마다 확인 → 인벤토리에 넣음 (가방이 꽉 차 있으면 비우라고 안내하고 선택은 남겨 둠)
- 받은 장비는 보스 드롭과 같은 방식으로 만든다 (등급 · 단련 효과 무작위)

## 5. 연희의 별 부적 (전용 장신구)
| 항목 | 내용 |
|---|---|
| 종류 · 레벨 | **펜던트** · Lv.90 |
| 기본 능력치 | 모든 능력치 +12 · 최대 HP +10% |
| 특수 효과 **"연희의 응원"** | 쓰러질 만큼 큰 피해를 받으면 **한 번 HP 1로 버팀** + "힘내요!" 글자와 작은 별빛 연출 · 재사용 3분 (버프 칸에 재사용 남은 시간 표시) |
| 설명 | "별 이야기를 좋아하는 소녀 연희가 직접 만든 부적. 위험할 때 한 번 지켜 준다." |
| 기타 | 1개만 받음. 팔기 · 버리기 불가 (선물이므로), 강화 · 각인은 일반 장신구처럼 가능 |
- 같은 칸의 "계승자의 펜던트"(Lv.100, 모든 능력치 +15 · 공격력)와 비교해 숫자는 조금 낮고 지켜 주는 효과로 개성을 줌

## 구현 메모 (완료)
- NPC `yeonhee_rag`(라그하르트) · `yeonhee_nox`(녹스게이트), 별 머리핀은 NPC 정의의 `pin` 색으로 `world.js`가 그림
- 퀘스트 `c3_s5` (`story3.js`, 시작 연희 · 완료 아스트라, 보상 골드 120,000 + 부적, `heroPick: 2`, `eliteRecord: true`)
- `quest.js`: 정예 처치 기록 `p.d.flags['elite:id']`, 수락 시 반영, 완료 시 `p.d.flags.heroPick` + 고르기 창
- `dialog.js`: 아스트라에게 남은 선택이 있으면 "✦ 영웅의 갑옷 고르기" 메뉴. `windows3.js` `G.Win.heroset`
- `player.die()`: 별 부적 착용 시 한 번 HP 1 (`cheerCd` 180초), 버프 칸에 재사용 표시. `ui.js` 판매 금지 · 툴팁
- 테스트 모드 순간이동 창에 "정예 처치 기록 채우기"
- (수정) 시작 조건: **실제 게임은 3장 "광산 도시"(볼가 보고) 완료 뒤 그대로**, **테스트 모드만** 3장부터 바로 (`p.d.dev`). 테스트 모드 3장 시작에서 받을 수 없던 문제. 받은 뒤 연희에게 말을 걸면 진행 상황이 보임 (실제 게임도)

## 7. 테스트
- 퀘스트 받기 전 정예 2종 처치 → 받으면 2개 ✔ → 나머지 처치 → 아스트라 완료 → 2개 선택 + 부적 → 인벤토리
- 1개만 고르고 닫기 → 아스트라 대화 → 남은 1개 다시 선택. 완료 후 다시 받을 수 없음
- 직업 4종 무기 칸, 가방이 꽉 찼을 때, 부적 팔기·버리기 막힘
- 연희의 응원: 큰 피해에서 HP 1로 버팀 → 3분 안에는 다시 안 됨, 버프 칸 표시
- 계승자 장비 Lv.90 착용 · 세트 효과, 녹스 드롭 그대로
- 회귀: 1.7.10 스킬, 1.7.9 버프 칸, 1.6.1
