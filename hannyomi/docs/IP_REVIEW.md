# 메이플스토리와 겹쳐 보이는 시스템 목록 (높음·중간 → 1.6.1에서 반영 완료)

2026-11-04 작성. 상용 출시(Play Store 등)를 대비해, 다른 게임과 겹쳐 보일 수 있는 이름·구조를 정리하고 바꿀 방향을 제안한다.
**이 문서는 제안이다. 사용자가 고른 항목만 별도 빌드(예: 1.6.1 또는 1.7)에서 반영한다.** 법률 자문이 아니며, 출시 전 전문가 확인을 받는다.

## 판단 기준
- **높음**: 이름이 그대로 같거나, 이름 + 수치/색 + 구조가 함께 같아 "그 게임"을 바로 떠올리게 하는 것 → 꼭 바꾸기
- **중간**: 하나하나는 흔하지만 조합이 겹쳐 보이는 것 → 이름을 바꾸고 구조도 일부 바꾸기 권장
- **낮음**: 장르 전반에서 흔한 것 → 그대로 둬도 됨 (원하면 손질)

## 반영할 때 함께 고칠 것 (작업 범위 메모)
- 아이템 이름·설명, 상점 목록, 툴팁, 튜토리얼 안내, 도움말(F1), 퀘스트 대사·보상 문구, README
- 구조를 바꾸는 항목(3·4·5·6·7)은 **세이브 변환 코드**가 필요 (`G.Save.VERSION` 올리고 `G.Save.upgrade()`에 추가)
- 이름만 바꾸는 항목(1·2·8·9·11)은 내부 id를 그대로 두면 세이브 영향 없음
