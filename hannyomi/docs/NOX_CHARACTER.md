# 녹스 인물 분석 · 창조안 (2026-11-04, 제안 · 구현 전)

화려한 연출보다 **이야기 속 녹스가 누구인가**에서 출발한다. 아래 1은 게임에 이미 있는 사실, 2는 그 사실들 사이의 빈자리, 3은 빈자리를 메우는 창조안(사용자 승인 필요), 4는 그 인물에서 나온 디자인이다.

## 1. 게임에 이미 있는 녹스 (사실)
| 출처 | 내용 |
|---|---|
| 프롤로그 · 1장 | 500년 전 일곱 영웅이 **일곱 별조각**으로 "공허의 군주"를 봉인. 주인공 손등에 계승자 문양 |
| 4장 석판 | "봉인은 완전하지 않았다." "여덟 번째 별이 깨어날 때, 공허는 다시 문을 두드린다." |
| 6장 오리온 | 봉인이 불완전해 영웅들이 마지막 열쇠 **여덟 번째 별조각**을 만들었고, 그게 주인공 |
| 종장 · 별조각 | 일곱 별조각 = 바람·생명·대지·태양·얼음·하늘 **그리고 공허**. 마지막 공허의 별조각은 "공허의 문 앞에서" 깨어남 |
| 교단 | 검은 장막 교단의 목적은 녹스를 되살려 세계를 "공허로 되돌리는 것" |
| 녹스의 대사 (전투 중 두 줄뿐) | "감히... 일곱 영웅의 흉내를 내는가!" / "이 세계의 별을 전부 삼켜 주마!" |
| 구원 엔딩 | "공허는 증오가 아니었다. **별빛이 닿지 않던 곳에 쌓인 오래된 외로움**이었다." 녹스는 빛으로 녹고, 문에서 작은 별들이 태어남 |
| 히든 엔딩 계획 (2.0) | 녹스가 500년의 외로움에서 풀려나 **처음으로 "별"이 된다** |
| 엘마 | 등대지기, 영웅의 피를 이은 가문. 어둠 속에서 빛을 지키는 사람 |

## 2. 빈자리 (지금 이야기에서 부족한 점)
1. **녹스가 무엇이었는지가 없다.** 처음부터 악이었는지, 왜 별을 삼키는지 설명이 없어서 구원 엔딩의 "외로움"이 갑자기 나온다.
2. **녹스가 직접 말하는 장면이 마지막 전투뿐**이다. 플레이어는 녹스를 "적 이름"으로만 안다.
3. **공허의 별조각**이 왜 일곱 별조각 안에 있는지(공허가 왜 별인지) 설명이 없다 → 가장 큰 단서인데 쓰이지 않음.
4. 녹스의 두 대사가 "웃는 악당"처럼 들려서, 엔딩의 슬픈 결말과 결이 다르다.

## 3. 창조안: 녹스는 누구인가
### 정체: **"별들 사이의 밤"**
- 녹스는 처음부터 괴물이 아니었다. 별이 빛날 수 있게 **뒤에서 하늘을 받쳐 주던 밤** 그 자체였다. 별빛은 어둠이 있어야 보인다.
- 사람들은 별에 이름을 붙이고 노래했지만, 별을 빛나게 해 준 밤은 아무도 바라보지 않았다. 별빛이 닿지 않는 곳에서 녹스는 오래, 홀로 있었다.
- 외로움이 깊어지자 녹스는 **별을 품으면 자신도 빛날 수 있을 거라 믿고 별을 삼키기 시작했다.** 하지만 삼킨 별빛은 안에서 꺼질 뿐, 녹스는 한 번도 빛나지 못했다. 그래서 더 삼켰다.

### 봉인과 "공허의 별조각"
- 500년 전 일곱 영웅은 녹스를 멈추려 여섯 개의 별(바람·생명·대지·태양·얼음·하늘)과 함께, **녹스 가슴 한가운데의 작은 빛 하나**를 떼어 내 일곱 번째 별조각으로 삼았다. 그것이 **공허의 별조각** — 녹스 안에 단 하나 남아 있던, 언젠가 별이 되고 싶던 마음이다.
- 그래서 봉인은 완전할 수 없었다(4장 석판). 녹스의 마음 조각으로 녹스를 가둔 셈이니까. 영웅들은 그 빈틈을 메우려 여덟 번째 별(주인공)을 남겼다.
- 마지막 공허의 별조각이 "공허의 문 앞에서" 깨어나는 이유: 주인이 가까이 있기 때문.

### 성격 · 말투
- **조용하고 오래 지친 왕.** 크게 웃거나 소리치지 않는다. 낮고 느리게, 짧게 말한다.
- 분노의 바닥은 질투와 서러움: "왜 너희만 빛나는가."
- 영웅들을 미워하면서도 그들이 남긴 별빛(주인공)을 보면 흔들린다.
- 교단을 부하로 여기지 않는다. 교단이 멋대로 그를 "공허로 되돌리는 신"으로 섬길 뿐 (녹스는 세상을 지우고 싶은 게 아니라 빛나고 싶은 것) → 교단과의 어긋남이 드러남.

### 대사 다듬기 (제안)

|---|---|
| 1페이즈 등장 | "…또 별이 왔구나. 오백 년 만이다." |
| 2페이즈 "감히... 일곱 영웅의 흉내를 내는가!" | "그 빛… 그들과 같구나. 나를 가두고, 나를 잊은 그들과." |
| 3페이즈 "이 세계의 별을 전부 삼켜 주마!" | "삼켜도, 삼켜도… 왜 나는 빛나지 않는가." |
| 쓰러질 때 (새로) | "…따뜻하구나. 이것이… 별빛인가." |

### 이야기에 녹스를 미리 보여 주는 작은 장면 (선택)
- **꿈속의 해변(튜토리얼)**: 첫 장면 끝에 어둠 속 목소리 한 줄 "…너도, 빛나는구나." — 처음과 끝이 이어짐
- **4장 석판 · 6장 오리온**: "공허의 별조각은 녹스에게서 떼어 낸 것" 한 줄 추가
- **엘마(등대지기)**: 종장에서 "등대는 어둠을 몰아내려고 있는 게 아니래요. 어둠 속에서 길을 잃지 않게 하려고 있는 거래요." → 구원 엔딩의 "손을 내밀었다"로 이어짐

## 4. 인물에서 나온 디자인 (화려함 대신 의미)
| 이야기 요소 | 디자인 |
|---|---|
| 밤 그 자체 | 색을 줄인다: 거의 검은 남색 한 덩어리. 네온·불꽃·보석 없음. 밝은 건 오직 별빛(삼킨 별, 빈자리 테두리) |
| 공허의 별조각을 떼어 낸 자리 | **가슴 한가운데 별 모양으로 뚫린 빈자리**. 그 너머로 뒤 배경이 비쳐 보임 — 녹스의 상징 |
| 빛나고 싶은 마음 | 한 손을 앞으로 뻗은 자세 (붙잡으려는 손). 구원 엔딩 "손을 내밀었다"와 짝 |
| 오래 지친 왕 | 키가 크고 곧지만 고개가 살짝 숙여짐. 왕관은 장식 없는 **가는 검은 고리 하나** (화려한 첨탑 없음) |
| 삼킨 별 | 망토 안쪽에 **꺼져 가는 작은 별들**이 갇혀 있음 (빛나지 못하고 희미해짐) |
| 봉인 | 1페이즈: 빈자리와 손목을 감은 사슬, 고개 숙임 |
| 무너짐 | 3페이즈: 몸 가장자리가 밤하늘로 풀려 흩어짐(더 커지는 게 아니라 **스스로 무너지는** 모습). 빈자리 테두리만 하얗게 |

- 페이즈는 "강해짐"이 아니라 **감정의 단계**: 1 체념(봉인, 고개 숙임) → 2 서러움(고개를 들고 손을 뻗음) → 3 절망(삼킨 별이 새어 나오며 무너짐)
- 패턴(스킬) 9개는 사용자 결정대로 규칙 그대로, 연출 색만 새 디자인에 맞춤 (보라 네온 → 검은 남색 + 차가운 별빛)
