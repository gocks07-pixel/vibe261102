# 빌드 1.8 계획: 스킬 효과음 (승인됨 · 구현 대기)

2026-11-03 확정. 사용자가 "1.8 진행해 줘"라고 요청하면 구현한다. 1.7 다음, EXE 빌드 전.
스킬의 수치·이펙트는 바꾸지 않는다. 소리만 추가한다.

## 지금 상태 (1.4)
- 스킬 119개 (공격 68, 버프 20, 패시브 28, 기타 3). 1.5에서 40개가 늘어 약 160개가 된다
- 사용할 때 소리는 모든 스킬이 같은 "skill" 하나, 타격음은 일반/치명타 2종뿐

## 1. 스킬마다 다른 효과음
- 패시브를 뺀 약 130개 스킬에 소리를 붙인다
- 파일 없이 Web Audio로 합성 (1.4 음악 엔진 `G.Synth`의 악기·잡음·타악기 음색 재사용). 전체 약 20~40KB
- 만드는 순서
  1. 계열별 기본 소리: 검 베기(바람 가르는 소리), 활(시위 튕김), 불(화르륵), 얼음(쨍그랑), 번개(지지직), 독·암흑(낮은 웅웅), 회복·버프(상승하는 반짝임), 이동(휙)
  2. 스킬마다 변화: 같은 계열이라도 음 높이·길이·겹치는 소리를 달리해 구별되게. 차수가 높을수록 묵직하고 화려하게
  3. 4차 대표 스킬(직업마다 가장 강한 기술)은 전용 소리
- 사용할 때 나는 소리(시전음)와 맞을 때 나는 소리(타격음)를 나눈다

## 2. 소리가 겹칠 때
- 여러 마리를 동시에 때려도 시끄럽지 않게, 같은 소리는 동시에 몇 개까지만 나게 제한
- 효과음 음량은 1.4 음향 설정(효과음 켬/끔·음량)을 그대로 따른다

## 3. 확인 방법
- 음악 감상실처럼 직업·차수별로 스킬 소리를 모은 감상 페이지를 만들어 사용자에게 링크로 공유
- 사용자가 고칠 스킬만 알려 주면 그 소리만 다시 만든다

## 1.8 실제 구현 (2026-11-05 · 구현 완료)
계획(1.4 때 작성)보다 범위를 넓혀 지금 상태에 맞춰 구현했다.
- `src/core/sound.js` (새 파일): 효과음 레시피 95개 (`G.Sound.R`). 스킬 소리 = 레시피 × 음높이 × 크기
  - 레시피 고르기: 직접 정한 것(`SKILL_SOUND`) → 1.7.10~1.7.11 전용 투사체·연출(`BY_PROJ` · `BY_FX`) → 속성 + 공격 방식(`BY_KIND`)
  - 음높이는 차수와 스킬 id로 조금씩 달라짐 → 소리 나는 스킬 122개 중 120개가 서로 다른 조합 (패시브 37개는 소리 없음)
  - 버프는 속성별 악기 아르페지오, 4차 각성은 팀파니 + 종
- 타격음: 속성 7가지 + 치명타 (`G.Sound.hit`, `combat.js`)
- 효과: 화상 · 빙결 · 표식 · 독 쌓임 · 튕기는 번개 · 지연 폭발 · 땅 갈라짐 · 조준음 (조준 스킬은 조준음 → 쏠 때 소리)
- 몬스터 스킬 8가지 틀 (`monskill.js`), 보스 패턴 시작 소리 (`boss.js`, 패턴 종류별 16가지), 둘 다 플레이어와 멀수록 작게
- 특수: 녹스의 등불이 켜지는 소리 (`world.js`), 연희의 응원 (`player.die`)
- 몰림 방지: 같은 소리는 0.08초 안에 2~3개까지만 (`G.Sound.LIMIT`)
- 확인 페이지 "한요미 소리 감상실": 스킬 · 타격 · 효과 · 몬스터 · 보스 소리 + 배경음악 바꾸기 전과 후
