# 과금없이 즐기는 연희의 RPG 대모험

기억을 잃은 **여덟 번째 별**이 일곱 별조각을 모으며 자신을 찾아가는 2D 횡스크롤 액션 RPG입니다.

## ▶ 플레이하기
**https://gocks07-pixel.github.io/rpg-adventure/**

- **PC**: 크롬 · 엣지로 열기. 키보드로 조작 (게임 안에서 F1)
- **아이폰**: 사파리로 열기 → 공유 버튼 → "홈 화면에 추가" → 홈 화면의 별 아이콘으로 열면 전체 화면
- **갤럭시**: 크롬으로 열기 → 메뉴(⋮) → "홈 화면에 추가"
- 휴대폰은 가로로 들고, 왼쪽 방향 패드 · 오른쪽 공격 · 점프 · 스킬 버튼으로 플레이
- 한 번 열면 인터넷이 없어도 플레이할 수 있습니다

## 세이브
- 세이브는 이 기기의 브라우저 안에 저장됩니다 (슬롯 3개)
- 가끔 **메뉴 → 💾 세이브 옮기기**에서 파일이나 글자로 내보내 두세요. 다른 기기나 PC 프로그램으로 옮길 때도 이 기능을 씁니다
- 아이폰은 사파리와 홈 화면 앱의 저장 공간이 따로입니다 (세이브 옮기기로 옮길 수 있어요)
