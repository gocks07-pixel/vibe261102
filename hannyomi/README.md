# 한요미의 대모험 — 1.9 빌드

세계관 "아르셀리아 연대기"의 튜토리얼 ~ 엔딩 (Lv.1~100) 플레이 가능 버전입니다. 배경음악과 효과음이 함께 나옵니다.

## 실행 방법
- **바로 플레이**: `index.html` 을 크롬/엣지로 열면 됩니다. (저장은 브라우저에 됨)
- **EXE로 실행/빌드** (Node.js 필요: https://nodejs.org 에서 LTS 설치)
  ```
  npm install          # 처음 한 번
  npm start            # EXE 창으로 실행 (테스트)
  npm run build        # dist 폴더에 설치 없이 실행되는 포터블 EXE 생성
  npm run build:setup  # 설치형 Setup.exe 생성
  ```
  EXE 세이브 파일 위치: `문서\Hannyomi\save_A.json`, `save_B.json`, `save_C.json` (슬롯 3개)

## 조작법 (게임 안에서 F1)
| 키 | 기능 |
|---|---|
| ← → | 이동 (둘 다 누르면 나중에 누른 쪽) |
| Space | 점프 · 공중에서 한 번 더: 2단 점프 |
| ↓ + Space | 발판 아래로 |
| Z | 기본 공격 (누르고 있으면 연속) |
| 1 ~ 6 | 스킬 단축키 |
| ↑ | 포탈 이동 / NPC 대화 (NPC 클릭도 가능) |
| Enter | 대화 넘기기 |
| H / J | HP / MP 회복약 |
| S / E / I / K / Q | 스탯 / 장비 / 인벤토리 / 스킬 / 퀘스트 |
| M | 지도 (월드맵 / 현재 맵) |
| F1 | 단축키 전체 안내 |
| Esc | 창 닫기 / 메뉴 |
| F11 | 전체화면 (EXE) |

오른쪽 위 퀘스트를 더블클릭하면 길 안내가 켜집니다.

## 1.7.2에서 바뀐 점 (하늘섬 아에로스 개편)

## 1.6.1에서 바뀐 점 (고유 시스템)
- 이름: 회복약(들풀·해초·진주 회복약, 생명수, 별빛 생명수 / 이슬 한 모금, 맑은 이슬, 달빛 이슬, 별이슬), 장비 등급(평범 · 반짝임 · 빛남 · 찬란 · 별의 축복), 귀환의 깃털, 여행자의 나침반, 힘·민첩·지혜·감각, 능력 포인트·기술 포인트, 표류자, 각성 Ⅰ~Ⅳ, 이끼 덩어리, 용암 방울, 별빛 도약
- 공명석 · 별자리 각인: 줄 하나를 골라 다시 새기고, 공명 게이지(5 / 15 / 35)가 차면 등급이 확정으로 오름
- 대장장이 "장비 단련": 무기·방어구 상인에게 골드(장비 레벨 × 60 + 500)를 내고 단련 효과를 다시 굴림 (불꽃석 폐지, 1개당 1,500 G 환급)
- 별빛 각인서 한 종류: 칸 단계에 따라 성공률 100% → 30%, 실패해도 칸은 남음, 강화 +1당 능력치 1.5배 (옛 주문서는 각인서 2·3장으로 변환)
- 능력 포인트: 레벨당 4 + 각성 후 주스탯 자동 +1
- 별의 장막: 최대 HP 비례 피해 흡수 보호막 (마법사 1차, 서리 갑옷)
- 기본 키: 점프 Space, 공격 Z (Alt·Ctrl은 키 설정에서 지정 가능)
- 각성할 때 별빛 기둥 연출
